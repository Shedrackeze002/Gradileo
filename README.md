# Gradileo

Gradileo is a mastery-based learning platform for mathematics. Teachers publish lessons,
present them in class, and assign work in one click. Students learn, practise and get
feedback. An AI teaching assistant reads every answer and suggests the next step for each
student and for the class.

It covers **every Alberta mathematics course from Grade 5 to Grade 12: Math 5, 6, 7, 8 and 9; Math 10C, 10-3 and 10-4; Math 20-1, 20-2, 20-3 and 20-4; and Math 30-1, 30-2, 30-3 and Math 31**.

| **Questions** | Every skill generates unlimited fresh questions at three difficulty levels, with hints, worked solutions and a forgiving math input (fractions, radicals, exponents, equations, points, graphs). Each student gets different numbers, so answers cannot be copied. |
| **Work types** | Lesson reading, video, reading, practice, classwork, homework, quiz and exam. Instant or delayed feedback, attempts, time limits, hints, "try a similar question", shuffling, open and due dates, late work, and targeting individual students. Quizzes and exams can use exam mode: full screen, exits recorded for the teacher, an optional lock or automatic submission after a set number of exits, and an optional camera-on check (nothing is recorded). |
| **Mastery** | Bayesian Knowledge Tracing per student and skill with five levels: Not started, Attempted, Familiar, Proficient, Mastered. Spaced review is suggested when a skill may be fading. |
| **Reminders** | Students are notified when work is assigned. Before the deadline, only students who have **not** submitted are reminded (24 h and 2 h by default, configurable). |
| **AI assistant** | Powered by MiniMax (`MiniMax-M3.1-Flash`) with an offline analyst as a fallback. It reports strengths, gaps, likely misconceptions, areas of growth and suggested groups, and proposes actions the teacher approves with one click. An optional autopilot assigns targeted practice after graded work. |
| **Admin console** | For running Gradileo across a school or district: platform overview, every user and class, teacher approval, admin roles, password resets, disabling accounts, sign-up settings, an audit log, and an inbox of course requests from students and teachers, where approving one opens a GitHub issue for a build session. |
| **Presenting** | Every lesson becomes a 16:9 slide deck that builds point by point, with transitions, worked examples revealed step by step and the lesson's interactive questions on "Your turn" slides. Draw on any slide or open a whiteboard (pen pressure, palm rejection) and save boards to the lesson; class timer, random student picker, blank screen, embedded videos and Desmos/GeoGebra activities. Live class questions go to every student's device, with the results on the slide, and students send their own questions while the teacher presents: each pops up to answer or skip, and a Questions slide gathers them at the end. Teachers hide what they will not teach; students still see the whole lesson. |
| **Self-paced study** | Students can sign up without a class code. A few questions (grade, plans, how mathematics feels) give a recommended course that follows Alberta's course sequences, an optional 6-question placement check shows whether they are ready or which skills to review, and a self-paced section opens with every lesson. The AI acts as tutor: **Start with your AI tutor** presents any lesson like a teacher, slide by slide and out loud in the explainer videos' voice (with captions), stops for each "Your turn" question, plays the explainer videos and answers the student's own questions; it also marks the next lesson, suggests practice and assigns targeted practice when a skill stays weak. Students can study several courses and join teachers' classes too; a class can ask the teacher to approve each student who uses its code. |
| **Explainer videos** | Animated explainers built from scripts, like the lessons: labelled triangles and diagrams (a cliff and a boat, a lighthouse, a clinometer), maths written step by step, a calculator, and a "Your turn" question with a countdown, with natural narration from an open text-to-speech model, captions, thumbnails and YouTube chapters. Lessons show their videos in a player that pauses at each "Your turn" and asks the question; administrators link each upload on the Videos page. The first videos cover Math 10C Unit 2 (lessons 2.1 to 2.4); see [video/README.md](video/README.md). |
| **Teacher tools** | Class overview, curriculum publishing, present mode, assignment builder with student preview and **Draft with AI** (choose the lessons, number and kinds of questions, difficulty and focus, and the AI drafts homework, a quiz or an exam: mostly generated questions with fresh numbers for every student, plus its own multiple-choice, short-answer and written questions with answers and marking guides, checked before the teacher reviews and publishes), per-question analysis with sample wrong answers, grading of written responses, gradebook with optional category weights, mastery heatmap, roster with generated logins and printable cards, announcements, CSV export, and suggested lesson edits (an administrator approves them, then every class sees the change). |

## Try it

```bash
npm install
npm run dev
```

Open http://localhost:5173 and choose **Try the teacher demo** or **Try as a student**. The demo
runs entirely in your browser with a sample class of 16 students, so no server is needed. Open the
student demo in a second tab to watch notifications and submissions arrive live.

## Going live

1. **Gradileo** runs at [gradileo.com](https://gradileo.com) on Cloudflare, deployed by GitHub
   Actions after the tests pass; its old github.io address redirects there. A copy of this
   repository can run on GitHub Pages instead: push to `main`, set *Settings → Pages → Source* to
   *GitHub Actions*, and remove `MOVED_TO` from the deploy workflow.
2. **Real accounts:** create a free Supabase project, push the database and functions, and add
   two repository variables. Follow [docs/SETUP.md](docs/SETUP.md).
3. **Your own domain:** Gradileo runs on Cloudflare at gradileo.com; add two repository secrets
   and the deploy publishes there too. GitHub Pages with a custom domain also works (both in
   SETUP.md).

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start the app (demo mode unless Supabase variables are set). |
| `npm test` | Engine, generator and lesson tests (every generated question is checked against its own answer key). |
| `npm run test:e2e` | Browser tests of the teacher → student → teacher loop, every page, and phone layouts. |
| `npm run test:db` | Database policy and reminder tests on any PostgreSQL 15+ server (`PGHOST`, `PGUSER`, …). |
| `npm run functions:check` | Type-check the Supabase Edge Functions with Deno. |
| `npm run build` | Production build (Cloudflare or GitHub Pages). |
| `npm run db:push` / `npm run functions:deploy` | Deploy the backend with the Supabase CLI. |

## Project layout

```
engine/            Shared learning engine (runs in the browser and in Edge Functions)
  curriculum/      Courses, lessons metadata and question generators
  ai/              MiniMax client, prompts, validation and the offline analyst
src/
  content/         Lesson text (Markdown with worked-example and check directives)
  features/        Teacher, student, lesson, player, AI and settings screens
  data/            Data API with a browser demo backend and a Supabase backend
supabase/
  migrations/      Schema, row-level security, triggers, RPCs and scheduled reminders
  functions/       grade-submission, ai-agent, ai-tutor, create-students, send-emails, admin-users, join-class
  tests/           Database behaviour tests
tests/e2e/         Playwright tests
```
