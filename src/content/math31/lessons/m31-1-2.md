The favourite base for exponentials and logarithms in calculus is the number $e$, and calculus measures every angle in radians. This lesson brings the logarithm and trigonometry skills from Grade 12 Pre-calculus up to date for calculus.

## Logarithms and the number e

:::definition Natural logarithm
$\ln x = \log_e x$, the logarithm with base $e \approx 2.71828$. Because $\ln$ and $e^x$ are inverses, $\ln(e^x) = x$ for every $x$ and $e^{\ln x} = x$ for $x > 0$.
:::

The laws of logarithms hold for $\ln$, for $M, N > 0$:

$$\ln(MN) = \ln M + \ln N, \qquad \ln\left(\frac{M}{N}\right) = \ln M - \ln N, \qquad \ln(M^k) = k\ln M$$

:::example Using the laws
Given $\ln a = 2$ and $\ln b = 0.5$, evaluate $\ln\left(\dfrac{a^3}{b}\right)$.
@step $\ln\left(\dfrac{a^3}{b}\right) = 3\ln a - \ln b$
@step $= 3(2) - 0.5$
@answer $5.5$
:::

To solve an exponential equation, isolate the power of $e$ and take $\ln$ of both sides.

:::example Solving with ln
Solve $3e^{0.4t} - 2 = 13$. Round to the nearest thousandth.
@step $3e^{0.4t} = 15$, so $e^{0.4t} = 5$.
@step $0.4t = \ln 5$
@step $t = \dfrac{\ln 5}{0.4} \approx 4.024$
@answer $t \approx 4.024$
:::

:::example A logarithmic equation
Solve $\ln x + \ln(x - 2) = \ln 8$.
@step Product law: $\ln(x(x - 2)) = \ln 8$, so $x^2 - 2x = 8$.
@step $x^2 - 2x - 8 = 0$ factors as $(x - 4)(x + 2) = 0$, so $x = 4$ or $x = -2$.
@step Reject $x = -2$: $\ln(-2)$ is undefined.
@answer $x = 4$
:::

:::example A quadratic in disguise
Solve $e^{2x} - 5e^x + 6 = 0$. Round to the nearest thousandth.
@step $e^{2x} = (e^x)^2$, so let $u = e^x$: $u^2 - 5u + 6 = 0$.
@step $(u - 2)(u - 3) = 0$, so $e^x = 2$ or $e^x = 3$.
@step Take $\ln$: $x = \ln 2 \approx 0.693$ or $x = \ln 3 \approx 1.099$.
@answer $x \approx 0.693$ or $x \approx 1.099$
:::

:::mistake The log of a sum
There is no law for $\ln(M + N)$. In particular, $\ln(x + 2) \ne \ln x + \ln 2$.
:::

## Radians and exact values

:::definition Radian
The angle at the centre of a circle that cuts off an arc equal in length to the radius. A full turn is $2\pi$ radians, so $\pi \text{ rad} = 180^\circ$.
:::

To convert, multiply by $\dfrac{\pi}{180^\circ}$ (degrees to radians) or by $\dfrac{180^\circ}{\pi}$ (radians to degrees): $135^\circ = \dfrac{135\pi}{180} = \dfrac{3\pi}{4}$, and $\dfrac{7\pi}{6} = \dfrac{7(180^\circ)}{6} = 210^\circ$.

Calculus formulas such as $\dfrac{d}{dx}\sin x = \cos x$ are true only in radians, so set your calculator to radian mode for this course.

The four marked angles all have reference angle $\frac{\pi}{6}$, so their sines and cosines are $\pm\frac{1}{2}$ and $\pm\frac{\sqrt{3}}{2}$. The quadrant decides the signs.

:::example Exact values
Find the exact values of $\cos\frac{5\pi}{6}$ and $\sin\frac{7\pi}{4}$.
@step $\frac{5\pi}{6}$ is in quadrant II with reference angle $\pi - \frac{5\pi}{6} = \frac{\pi}{6}$. Cosine is negative in quadrant II, so $\cos\frac{5\pi}{6} = -\cos\frac{\pi}{6} = -\frac{\sqrt{3}}{2}$.
@step $\frac{7\pi}{4}$ is in quadrant IV with reference angle $2\pi - \frac{7\pi}{4} = \frac{\pi}{4}$. Sine is negative in quadrant IV, so $\sin\frac{7\pi}{4} = -\frac{\sqrt{2}}{2}$.
@answer $\cos\frac{5\pi}{6} = -\frac{\sqrt{3}}{2}$ and $\sin\frac{7\pi}{4} = -\frac{\sqrt{2}}{2}$

## Identities you will use

| Type | Identities |
|---|---|
| Quotient and reciprocal | $\tan x = \dfrac{\sin x}{\cos x}$, $\sec x = \dfrac{1}{\cos x}$, $\csc x = \dfrac{1}{\sin x}$, $\cot x = \dfrac{\cos x}{\sin x}$ |
| Pythagorean | $\sin^2 x + \cos^2 x = 1$, $1 + \tan^2 x = \sec^2 x$ |
| Double angle | $\sin 2x = 2\sin x \cos x$, $\cos 2x = \cos^2 x - \sin^2 x = 1 - 2\sin^2 x = 2\cos^2 x - 1$ |

:::example Simplifying with identities
Simplify $\dfrac{1 - \cos^2 x}{\sin x \cos x}$.
@step Pythagorean identity: $1 - \cos^2 x = \sin^2 x$.
@step $\dfrac{\sin^2 x}{\sin x \cos x} = \dfrac{\sin x}{\cos x}$
@step Check at $x = \frac{\pi}{6}$: $\dfrac{1 - \frac{3}{4}}{\frac{1}{2} \cdot \frac{\sqrt{3}}{2}} = \dfrac{1}{\sqrt{3}} = \tan\frac{\pi}{6}$ ✓
@answer $\tan x$
:::

:::mistake The double angle
$\sin 2x$ is not $2\sin x$. At $x = \frac{\pi}{2}$, $\sin 2x = \sin \pi = 0$ but $2\sin\frac{\pi}{2} = 2$. Use $\sin 2x = 2\sin x \cos x$.
:::

## Solving trigonometric equations

Isolate the trigonometric function, find the reference angle, and use the quadrant signs to list every solution in $0 \le x < 2\pi$.

:::example A linear equation
Solve $2\sin x + 1 = 0$ for $0 \le x < 2\pi$.
@step $\sin x = -\frac{1}{2}$, so the reference angle is $\frac{\pi}{6}$.
@step Sine is negative in quadrants III and IV: $x = \pi + \frac{\pi}{6}$ and $x = 2\pi - \frac{\pi}{6}$.
@answer $x = \frac{7\pi}{6}$ or $x = \frac{11\pi}{6}$
:::

:::example A quadratic equation
Solve $2\cos^2 x - \cos x - 1 = 0$ for $0 \le x < 2\pi$.
@step Factor as a quadratic in $\cos x$: $(2\cos x + 1)(\cos x - 1) = 0$.
@step $\cos x = -\frac{1}{2}$ gives $x = \frac{2\pi}{3}$ and $x = \frac{4\pi}{3}$ (quadrants II and III).
@step $\cos x = 1$ gives $x = 0$.
@answer $x = 0,\ \frac{2\pi}{3},\ \frac{4\pi}{3}$
:::

:::example Using a double-angle identity
Solve $\sin 2x = \sin x$ for $0 \le x < 2\pi$.
@step $2\sin x \cos x - \sin x = 0$, so $\sin x\,(2\cos x - 1) = 0$.
@step $\sin x = 0$ gives $x = 0$ and $x = \pi$.
@step $\cos x = \frac{1}{2}$ gives $x = \frac{\pi}{3}$ and $x = \frac{5\pi}{3}$.
@answer $x = 0,\ \frac{\pi}{3},\ \pi,\ \frac{5\pi}{3}$
:::

:::mistake Dividing by a variable factor
Dividing both sides of $2\sin x \cos x = \sin x$ by $\sin x$ throws away the solutions where $\sin x = 0$. Move everything to one side and factor instead.
:::

:::summary
- Work in radians: $\pi \text{ rad} = 180^\circ$. Exact values come from a reference angle and the quadrant signs.
- Know the quotient, Pythagorean and double-angle identities; test a simplification by substituting a value.
- To solve a trigonometric equation, isolate or factor, then find every solution in $[0, 2\pi)$. Never divide by a factor that could be $0$.
- $\ln$ and $e^x$ are inverses. Isolate $e^{(\ldots)}$, then take $\ln$; check that every logarithm's argument is positive.
:::
