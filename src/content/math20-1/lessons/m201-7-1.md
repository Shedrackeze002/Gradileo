On a January morning in a northern town the temperature is $-23\,^{\circ}\text{C}$; by mid-afternoon it is $4\,^{\circ}\text{C}$. How big was the change? Questions about **size** — distance, change, error — ignore direction, and absolute value is the tool that does that.

## Absolute value as distance

:::definition Absolute value
The absolute value of a real number $a$, written $|a|$, is its distance from $0$ on a number line. Algebraically,
$$|a| = \begin{cases} a, & a \ge 0 \\ -a, & a < 0 \end{cases}$$
:::

The numbers $-5$ and $5$ are both 5 units from $0$, so $|{-}5| = |5| = 5$. In the second line of the definition, $-a$ is positive because $a$ is negative: $|{-}5| = -(-5) = 5$.

:::figure
{"type":"numberLine","min":-6,"max":6,"step":1,"points":[{"value":-5,"label":"−5"},{"value":5,"label":"5"}]}
:::

:::example Evaluating
Evaluate $|{-}7|$ and $|3 - 10|$.
@step $-7$ is 7 units from $0$, so $|{-}7| = 7$.
@step Work inside the bars first: $3 - 10 = -7$, so $|3 - 10| = |{-}7| = 7$.
@answer $7$ and $7$
:::

## Absolute value and the order of operations

Absolute value bars are grouping symbols, like brackets. Simplify inside them first, then take the absolute value, then finish the rest of the calculation.

:::example Several operations
Evaluate $3|{-}4| - |2 - 9|$.
@step Inside the bars: $|{-}4| = 4$ and $|2 - 9| = |{-}7| = 7$.
@step $3(4) - 7 = 12 - 7 = 5$
@answer $5$
:::

:::mistake Splitting the bars
$|3 - 10| = 7$, but $|3| - |10| = 3 - 10 = -7$. You cannot take the absolute value of each term separately. Also notice that a negative sign **outside** the bars stays: $-|{-}6| = -6$.
:::

:::check m201-abs-evaluate 2
:::

## Distance between two numbers

The distance between $a$ and $b$ on a number line is $|a - b|$. Because $|a - b| = |b - a|$, the order does not matter.

:::figure
{"type":"numberLine","min":-5,"max":8,"step":1,"points":[{"value":-4,"label":"A = −4"},{"value":7,"label":"B = 7"}]}
:::

:::example Two points
Find the distance between $A = -4$ and $B = 7$.
@step $|{-}4 - 7| = |{-}11| = 11$
@step Check the other order: $|7 - (-4)| = |11| = 11$ ✓
@answer 11 units
:::

:::example Temperature change
The temperature rose from $-23\,^{\circ}\text{C}$ to $4\,^{\circ}\text{C}$. Find the size of the change.
@step $|4 - (-23)| = |27| = 27$
@answer $27\,^{\circ}\text{C}$
:::

## Total distance and net change

A net change can hide a lot of movement, because moves up and down cancel. Total distance adds the **absolute values** of the individual changes.

:::example A survey drone
A drone climbs from 20 m to 65 m, descends to 30 m, then climbs to 50 m. Find the total vertical distance travelled and the net change in height.
@step Total: $|65 - 20| + |30 - 65| + |50 - 30| = 45 + 35 + 20 = 100$ m.
@step Net change: $50 - 20 = 30$ m.
@answer It travelled 100 m, but ended only 30 m higher.
:::

:::tip Exact answers
With fractions, find a common denominator inside the bars first: $\left|\tfrac{1}{2} - 4\right| = \left|{-}\tfrac{7}{2}\right| = \tfrac{7}{2}$.
:::

:::check m201-abs-evaluate 3
:::

:::summary
- $|a|$ is the distance from $a$ to $0$, so it is never negative.
- $|a| = a$ when $a \ge 0$ and $|a| = -a$ when $a < 0$.
- Bars are grouping symbols: simplify inside them first.
- The distance between $a$ and $b$ is $|a - b|$.
- Total distance adds absolute changes; net change can cancel.
:::
