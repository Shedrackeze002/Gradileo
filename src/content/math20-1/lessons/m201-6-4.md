Aisha can clear the snow from the community rink in 4 h, and Mateo can do it in 6 h. How long will it take if they work together? Not 5 h, and not 10 h — the answer comes from a **rational equation**, an equation with the variable in a denominator.

## Solving by multiplying by the LCD

:::definition Rational equation
An equation that contains at least one rational expression, such as $\dfrac{3}{x} + \dfrac{1}{2x} = \dfrac{7}{4}$.
:::

1. Find the non-permissible values.
2. Multiply **every** term on both sides by the lowest common denominator. The denominators disappear.
3. Solve the resulting polynomial equation.
4. Reject any answer that is non-permissible, and check the others.

:::example A linear result
Solve $\dfrac{3}{x} + \dfrac{1}{2x} = \dfrac{7}{4}$.
@step Restriction: $x \ne 0$. LCD: $4x$.
@step Multiply every term by $4x$: $12 + 2 = 7x$.
@step $x = 2$. Check: $\tfrac{3}{2} + \tfrac{1}{4} = \tfrac{7}{4}$ ✓
@answer $x = 2$
:::

:::

## Extraneous roots

Multiplying by an expression that contains the variable can create answers that do not satisfy the original equation. They are always non-permissible values.

:::definition Extraneous root
A solution of the transformed (multiplied-out) equation that is not a solution of the original equation.
:::

:::example No solution
Solve $\dfrac{x}{x - 3} = \dfrac{3}{x - 3} + 2$.
@step Restriction: $x \ne 3$. Multiply every term by $x - 3$: $x = 3 + 2(x - 3)$.
@step $x = 2x - 3$, so $x = 3$.
@step But $x = 3$ is non-permissible, so it is extraneous.
@answer No solution
:::

:::example A quadratic with one extraneous root
Solve $\dfrac{x}{x - 2} - \dfrac{3}{x + 1} = \dfrac{6}{x^2 - x - 2}$.
@step Factor: $x^2 - x - 2 = (x - 2)(x + 1)$, so $x \ne 2,\ -1$.
@step Multiply every term by $(x - 2)(x + 1)$: $x(x + 1) - 3(x - 2) = 6$.
@step $x^2 + x - 3x + 6 = 6$, so $x^2 - 2x = 0$ and $x(x - 2) = 0$: $x = 0$ or $x = 2$.
@step Reject $x = 2$. Check $x = 0$: left $0 - 3 = -3$; right $\tfrac{6}{-2} = -3$ ✓
@answer $x = 0$
:::

:::mistake Skipping the check
The algebra above produced $x = 2$ honestly, yet it is not a solution: it makes two of the denominators zero. Compare every answer with the restrictions before you report it.
:::

## Work-together problems

If a worker finishes a job in $a$ hours, they complete $\tfrac{1}{a}$ of the job each hour. Working together, the rates add:

$$\frac{1}{a} + \frac{1}{b} = \frac{1}{t}$$

:::example Clearing the rink
Aisha takes 4 h and Mateo takes 6 h. How long together?
@step $\dfrac{1}{4} + \dfrac{1}{6} = \dfrac{1}{t}$, with $t \ne 0$. Multiply by $12t$: $3t + 2t = 12$.
@step $5t = 12$, so $t = 2.4$.
@answer $2.4$ h (2 h 24 min)
:::

:::example One worker is slower
Pipe B takes 3 h longer than pipe A to fill a stock tank. Together they fill it in 2 h. How long does pipe A take alone?
@step Let $x$ be pipe A's time: $\dfrac{1}{x} + \dfrac{1}{x + 3} = \dfrac{1}{2}$, with $x \ne 0,\ -3$.
@step Multiply by $2x(x + 3)$: $2(x + 3) + 2x = x(x + 3)$, so $x^2 - x - 6 = 0$.
@step $(x - 3)(x + 2) = 0$: $x = 3$ or $x = -2$. A time cannot be negative.
@answer 3 h
:::

:::check m201-rational-apply 1
:::

## Travel with a current or wind

Time equals distance divided by speed. A current (or wind) adds to the speed going with it and subtracts going against it.

:::example Same time, different distances
In the same time, a boat travels 30 km downstream and 18 km upstream on a wide river. The current is 3 km/h. Find the boat's speed in still water.
@step Let $s$ be the speed in still water. Downstream $s + 3$, upstream $s - 3$.
@step Equal times: $\dfrac{30}{s + 3} = \dfrac{18}{s - 3}$. Cross-multiply: $30s - 90 = 18s + 54$.
@step $12s = 144$, so $s = 12$. Check: $\tfrac{30}{15} = 2$ h and $\tfrac{18}{9} = 2$ h ✓
@answer 12 km/h
:::

:::tip Number problems
"A number plus its reciprocal is $\tfrac{10}{3}$" becomes $x + \dfrac{1}{x} = \dfrac{10}{3}$. Multiply by $3x$: $3x^2 - 10x + 3 = 0$, so $(3x - 1)(x - 3) = 0$ and the number is $3$ or $\tfrac{1}{3}$.
:::

:::

:::check m201-rational-apply 3
:::

:::summary
- State the non-permissible values, then multiply every term by the LCD.
- Solve the polynomial equation that results.
- Reject extraneous roots (non-permissible values) and check the rest.
- Work problems: rates add, $\tfrac{1}{a} + \tfrac{1}{b} = \tfrac{1}{t}$.
- Motion problems: time $=$ distance $\div$ speed; a current adds or subtracts.
:::
