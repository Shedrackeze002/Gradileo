A square garden has an area of $49$ m². How long is each side? Answering that question means solving $x^2 = 49$, the simplest kind of quadratic equation.

## Quadratic equations

:::definition Quadratic equation
A **quadratic equation** is an equation in which the highest power of the variable is $2$. In this lesson we solve the simplest kind, which can be written as
$$x^2 = k$$
where $k$ is a number. A **solution** of the equation is a value of $x$ that makes it true.
:::

## Solving $x^2 = k$

Squaring and taking a square root are inverse operations, so we solve $x^2 = k$ by asking which numbers have a square of $k$. There are usually two, because a negative number multiplied by itself is positive.

:::example Two solutions
Solve $x^2 = 49$.
@step $7 \times 7 = 49$, so $x = 7$ is a solution.
@step $(-7) \times (-7) = 49$ as well, so $x = -7$ is also a solution.
@answer $x = 7$ or $x = -7$, which we can write as $x = \pm 7$.
:::

:::mistake Forgetting the negative solution
The symbol $\sqrt{49}$ means the positive root only, $7$. The equation $x^2 = 49$ asks for *every* number whose square is $49$, so it has two solutions: $7$ and $-7$.
:::

## How many solutions?

The number of solutions depends on the sign of $k$:

- When $k$ is positive, there are **two** solutions, $\sqrt{k}$ and $-\sqrt{k}$.
- When $k$ is zero, there is **one** solution, $x = 0$.
- When $k$ is negative, there is **no** solution among the real numbers, because the square of a number is never negative.

## Rearranging first

When the equation is not yet in the form $x^2 = k$, get $x^2$ by itself first.

:::example Rearranging before taking roots
Solve $x^2 - 81 = 0$.
@step Add $81$ to both sides: $x^2 = 81$
@step Take both square roots: $x = 9$ or $x = -9$
@answer $x = \pm 9$
:::

:::example An equation with no solution
Solve $x^2 + 16 = 0$.
@step Subtract $16$ from both sides: $x^2 = -16$
@step No real number has a negative square.
@answer The equation has no solution.
:::

## Solutions that are not whole numbers

When $k$ is not a perfect square, the solutions are irrational. We can leave them exact, as $\pm\sqrt{k}$, or round them with a calculator.

:::example An irrational solution
Solve $x^2 - 20 = 0$, to 2 decimal places.
@step $x^2 = 20$
@step $x = \sqrt{20}$ or $x = -\sqrt{20}$
@step $\sqrt{20} \approx 4.47$
@answer $x \approx 4.47$ or $x \approx -4.47$
:::

:::tip Check the context
An equation can have two solutions when the problem has only one sensible answer. The side of a square garden with an area of $49$ m² solves $x^2 = 49$, but a length cannot be negative, so the side is $7$ m.
:::

:::

:::summary
- A quadratic equation has $2$ as the highest power of its variable. The simplest kind is $x^2 = k$.
- $k > 0$: two solutions, $x = \pm\sqrt{k}$. $k = 0$: one solution, $x = 0$. $k < 0$: no real solution.
- Get $x^2$ by itself before taking square roots.
- When $k$ is not a perfect square, leave the solutions as $\pm\sqrt{k}$ or round them.
- In a context, keep only the solutions that make sense.
:::
