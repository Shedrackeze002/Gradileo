"If it rains, then the match is cancelled." Is this statement broken when it does not rain and the match is cancelled anyway? Logic answers questions like this with a table that lists every case.

## Statements and connectives

:::definition Truth table
A **statement** is a sentence that is either true (T) or false (F). A **truth table** lists every combination of truth values for the simple statements $p$ and $q$, and shows the truth value of a compound statement built from them in each case. With two statements there are four rows: TT, TF, FT and FF.
:::

We build compound statements with five connectives.

| Symbol | Read as | True when |
| --- | --- | --- |
| $\neg p$ | not $p$ | $p$ is false |
| $p \wedge q$ | $p$ and $q$ | both are true |
| $p \vee q$ | $p$ or $q$ | at least one is true |
| $p \Rightarrow q$ | if $p$ then $q$ | every case except $p$ true, $q$ false |
| $p \Leftrightarrow q$ | $p$ if and only if $q$ | $p$ and $q$ have the same truth value |

Here are the four of them that join two statements, in one table.

| $p$ | $q$ | $p \wedge q$ | $p \vee q$ | $p \Rightarrow q$ | $p \Leftrightarrow q$ |
| --- | --- | --- | --- | --- | --- |
| T | T | T | T | T | T |
| T | F | F | T | F | F |
| F | T | F | T | T | F |
| F | F | F | F | T | T |

:::check mx-truth-value 1
:::

## If–then

The implication $p \Rightarrow q$ is a promise: if $p$ happens, then $q$ will happen. The promise is broken only when $p$ is true and $q$ is false. When $p$ is false, the promise has not been tested, so the statement counts as true.

:::example The match
Let $p$: "it rains" and $q$: "the match is cancelled". It does not rain, and the match is cancelled. Is $p \Rightarrow q$ true?
@step $p$ is false and $q$ is true.
@step $p \Rightarrow q$ is false only when $p$ is true and $q$ is false. That is not this case.
@answer The statement is true.
:::

:::mistake "Or" includes both
In logic, $p \vee q$ is true when $p$ is true, when $q$ is true, and also when both are true. It is false only when both are false.
:::

:::check mx-truth-value 2
:::

For a longer statement we work from the inside out: negations first, then the brackets, then the connective that joins them.

:::example Working from the inside
$p$ is true and $q$ is false. Find the truth value of $\neg(p \wedge \neg q)$.
@step $\neg q$ is true.
@step $p \wedge \neg q$ joins true and true, so it is true.
@answer Its negation, $\neg(p \wedge \neg q)$, is false.
:::

:::check mx-truth-value 3
:::

## Completing a truth table

To complete a table we repeat this for all four rows, adding a column for each part of the statement.

:::example A table for $\neg p \vee q$
@step Write the four rows for $p$ and $q$, then a column for $\neg p$, then the final column.
@step In each row, $\neg p \vee q$ is false only when $\neg p$ and $q$ are both false.
@answer The final column is T, F, T, T.
:::

| $p$ | $q$ | $\neg p$ | $\neg p \vee q$ |
| --- | --- | --- | --- |
| T | T | F | T |
| T | F | F | F |
| F | T | T | T |
| F | F | T | T |

This is the same column as $p \Rightarrow q$. Two statements with the same column are **logically equivalent**: "if $p$ then $q$" says the same as "not $p$, or $q$".

## Tautologies and contradictions

A statement that is true in every row is a **tautology**, such as $p \vee \neg p$. A statement that is false in every row is a **contradiction**, such as $p \wedge \neg p$.

:::check mx-truth-table 3
:::

:::summary
- A truth table lists all four cases for $p$ and $q$: TT, TF, FT, FF.
- "And" needs both; "or" needs at least one; "if–then" fails only for true then false; "if and only if" needs the same value.
- Work from the inside out, one column at a time.
- A tautology is always true, and a contradiction is always false.
:::
