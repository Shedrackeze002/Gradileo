A bar chart works well when every class is the same width. When the classes have different widths, a wide class would look too important, so we draw a histogram, where the **area** of each bar shows the frequency.

## Frequency density

:::definition Frequency density
In a **histogram** the bars touch, the horizontal axis is a continuous scale, and the height of each bar is the **frequency density**:
$$\text{frequency density} = \frac{\text{frequency}}{\text{class width}}$$
So the **area** of each bar, width $\times$ height, is its frequency.
:::

:::example Working out frequency densities
The table shows the times some people took to finish a puzzle. Find the frequency densities.

| Time $t$ (minutes) | Frequency |
|---|---|
| $0 < t \le 10$ | $20$ |
| $10 < t \le 15$ | $30$ |
| $15 < t \le 20$ | $25$ |
| $20 < t \le 40$ | $16$ |

@step The class widths are $10,\ 5,\ 5$ and $20$.
@step $20 \div 10 = 2$, $\ 30 \div 5 = 6$, $\ 25 \div 5 = 5$, $\ 16 \div 20 = 0.8$
@answer The frequency densities are $2,\ 6,\ 5$ and $0.8$.
:::

## Reading a histogram

To find a frequency, multiply back: frequency $=$ frequency density $\times$ class width.

:::example A frequency and an estimate
Using the histogram above, estimate how many people took more than $30$ minutes.
@step The class $20 < t \le 40$ has a frequency density of $0.8$.
@step From $30$ to $40$ is a width of $10$, so the estimate is $0.8 \times 10 = 8$.
@answer About $8$ people took more than $30$ minutes.
:::

:::tip Part of a class
An estimate for part of a class assumes the values are spread evenly across it, so we take the area of just that part of the bar.
:::

:::summary
- Frequency density $= \dfrac{\text{frequency}}{\text{class width}}$, and it is the height of a histogram bar.
- The area of a bar is its frequency: frequency $=$ frequency density $\times$ class width.
- For part of a class, use the area of that part of the bar to estimate the frequency.
:::
