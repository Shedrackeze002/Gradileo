The product rule tells us how to differentiate a product. Reading it backwards gives a way to integrate one: integration by parts.

## The formula

:::definition Integration by parts
$$\int u\frac{dv}{dx}\,dx = uv - \int v\frac{du}{dx}\,dx.$$
Choose $u$ to be the part that gets simpler when differentiated, and $\dfrac{dv}{dx}$ to be a part you can integrate.
:::

:::example x times eˣ
Find $\displaystyle\int xe^x\,dx$.
@step Let $u = x$ and $\dfrac{dv}{dx} = e^x$, so $\dfrac{du}{dx} = 1$ and $v = e^x$.
@step $\displaystyle\int xe^x\,dx = xe^x - \int e^x\,dx$
@answer $xe^x - e^x + C$
:::

:::check mx-parts-indefinite 2

:::mistake Choosing u with ln x
With $\ln x$, always let $u = \ln x$, since $\dfrac{du}{dx} = \dfrac{1}{x}$ is simple and $\ln x$ is hard to integrate. Even $\displaystyle\int \ln x\,dx$ works this way, with $\dfrac{dv}{dx} = 1$: it gives $x\ln x - x + C$.
:::

:::check mx-parts-indefinite 3
:::

## Definite integrals by parts

For limits, $\displaystyle\int_a^b u\frac{dv}{dx}\,dx = \big[uv\big]_a^b - \int_a^b v\frac{du}{dx}\,dx$. For example,
$$\int_1^e \ln x\,dx = \big[x\ln x - x\big]_1^e = (e - e) - (0 - 1) = 1.$$

:::tip Twice for x²
For $\displaystyle\int x^2e^x\,dx$ or $\displaystyle\int x^2\cos x\,dx$, the first use of parts leaves an integral of $x$ times something, so use parts a second time.
:::

:::check mx-parts-definite 3
:::

:::summary
- $\displaystyle\int u\frac{dv}{dx}\,dx = uv - \int v\frac{du}{dx}\,dx$.
- Let $u$ be the power of $x$, except when there is a $\ln x$: then $u = \ln x$.
- Check an answer by differentiating it with the product rule.
:::
