When a scatter graph shows a straight-line pattern, we can draw a line of best fit by eye. The least squares regression line is the line of best fit that a calculation picks, so everyone who uses the same data gets the same line.

## The regression line of y on x

:::definition Least squares regression line
The **least squares regression line of $y$ on $x$** is the straight line $y = a + bx$ that makes the sum of the squared vertical distances from the points to the line as small as possible. Its gradient and intercept are
$$b = \frac{S_{xy}}{S_{xx}} \qquad a = \bar{y} - b\bar{x}$$
:::

In the figure, each short vertical segment is a **residual**, the gap between a data point and the line. The least squares line is the one line that makes the total of the squared residuals smallest. It always passes through the mean point $(\bar{x}, \bar{y})$, which is why $a = \bar{y} - b\bar{x}$.

The summary statistics are
$$S_{xx} = \sum x^2 - \frac{(\sum x)^2}{n} \qquad S_{xy} = \sum xy - \frac{\sum x \sum y}{n}$$
where $n$ is the number of pairs.

:::example From summary statistics
For some data on revision time $x$ and test mark $y$: $\bar{x} = 6$, $\bar{y} = 52$, $S_{xx} = 80$ and $S_{xy} = 240$. Find the regression line of $y$ on $x$.
@step $b = \dfrac{240}{80} = 3$
@step $a = 52 - 3 \times 6 = 34$
@answer $y = 34 + 3x$
:::

:::

:::example From a table
Find the regression line of $y$ on $x$ for the data $x$: $1, 2, 3, 4, 5$ and $y$: $3, 5, 4, 8, 10$.
@step $n = 5$, $\sum x = 15$, $\sum y = 30$, $\sum x^2 = 55$, $\sum xy = 107$
@step $S_{xx} = 55 - \dfrac{15^2}{5} = 10$ and $S_{xy} = 107 - \dfrac{15 \times 30}{5} = 17$
@step $b = \dfrac{17}{10} = 1.7$ and $a = 6 - 1.7 \times 3 = 0.9$
@answer $y = 0.9 + 1.7x$
:::

In statistics mode, most calculators give $a$ and $b$ straight from the table of data. Still write down the method, and keep the full value of $b$ when you work out $a$.
:::

## Using the line

The gradient $b$ tells us how much $y$ changes, on average, for each increase of $1$ in $x$. To estimate $y$ for a given $x$, we put the value of $x$ into the equation.

:::example Estimating
The regression line for some data, with $x$ from $2$ to $12$, is $y = 34 + 3x$. Estimate $y$ when $x = 7$, and explain what $3$ means.
@step $y = 34 + 3 \times 7 = 55$
@step For each extra hour of revision, the mark rises by about $3$ on average.
@answer $y \approx 55$
:::

An estimate for an $x$ inside the range of the data is called **interpolation**, and it is usually reliable when the correlation is strong. An estimate outside the range is **extrapolation**, which is not reliable, because nothing tells us that the pattern carries on beyond the data.

:::mistake Using the wrong line
The line of $y$ on $x$ is for estimating $y$ from $x$. Rearranging it to estimate $x$ from $y$ is not the same as the regression line of $x$ on $y$, so it is not the best estimate.
:::

:::check mx-regression-use 3
:::

:::summary
- The regression line of $y$ on $x$ is $y = a + bx$ with $b = \dfrac{S_{xy}}{S_{xx}}$ and $a = \bar{y} - b\bar{x}$.
- It passes through $(\bar{x}, \bar{y})$, and $b$ is the average change in $y$ for each unit of $x$.
- Interpolation inside the data is reliable; extrapolation outside it is not.
:::
