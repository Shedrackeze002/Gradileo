For a positive whole number $n$, $(1 + x)^n$ expands into a finite number of terms. For other powers, such as $(1 + x)^{-1}$ or $\sqrt{1 + x}$, the same formula still works, but it goes on for ever, and only makes sense when $x$ is small.

## The general binomial expansion

:::definition Binomial expansion for rational n
For any rational number $n$,
$$(1 + x)^n = 1 + nx + \frac{n(n - 1)}{2!}x^2 + \frac{n(n - 1)(n - 2)}{3!}x^3 + \cdots$$
When $n$ is not a positive whole number the series never ends, and it is **valid** (converges) only for $|x| < 1$.
:::

:::example A negative power
Expand $(1 + 2x)^{\frac{1}{2}}$ up to the term in $x^2$, and say when it is valid.
@step $n = \tfrac{1}{2}$ and the “$x$” is $2x$: $1 + \tfrac{1}{2}(2x) + \dfrac{\tfrac{1}{2}\left(-\tfrac{1}{2}\right)}{2}(2x)^2$
@step $= 1 + x - \tfrac{1}{8}(4x^2)$
@answer $(1 + 2x)^{\frac{1}{2}} \approx 1 + x - \tfrac{1}{2}x^2$, valid for $|2x| < 1$, that is $|x| < \tfrac{1}{2}$.
:::

:::mistake Raise the whole term
In $(1 + 2x)^n$, the $x^2$ term uses $(2x)^2 = 4x^2$, not $2x^2$. Put brackets round the whole term before raising it to a power.
:::

## Other first terms

For $(a + bx)^n$, take out a factor of $a^n$ first:
$$(a + bx)^n = a^n\left(1 + \frac{b}{a}x\right)^n,$$
which is valid for $\left|\dfrac{bx}{a}\right| < 1$, that is $|x| < \left|\dfrac{a}{b}\right|$. For example, $(4 + x)^{\frac{1}{2}} = 2\left(1 + \tfrac{x}{4}\right)^{\frac{1}{2}} = 2 + \tfrac{1}{4}x - \tfrac{1}{64}x^2 + \cdots$ for $|x| < 4$.

:::tip Approximating
A few terms of an expansion with a small $x$ give a good estimate: $\sqrt{1.02} = (1 + 0.02)^{\frac{1}{2}} \approx 1 + 0.01 - 0.00005 = 1.00995$.
:::

:::summary
- $(1 + x)^n = 1 + nx + \dfrac{n(n - 1)}{2!}x^2 + \cdots$ for any rational $n$, valid for $|x| < 1$.
- For $(1 + bx)^n$, replace $x$ by $bx$ throughout; valid for $|bx| < 1$.
- For $(a + bx)^n$, take out $a^n$ first; valid for $|x| < \left|\dfrac{a}{b}\right|$.
:::
