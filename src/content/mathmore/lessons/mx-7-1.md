A ruler says a pencil is $14$ cm long, to the nearest centimetre. Its true length is not exactly $14$ cm: it could be anything that rounds to $14$. An error interval says exactly which lengths those are.

## Error intervals from rounding

:::definition Error interval
The **error interval** of a rounded number is the range of values it could have been before it was rounded. It is written as an inequality, $a \le x < b$, where $a$ is the **lower bound** and $b$ is the **upper bound**.
:::

When a number is rounded, the true value can be up to **half a unit** either side, where the unit is what we rounded to. The lower bound is included, since it rounds up to the number. The upper bound is not included, since it would round up to the next number.

:::example Rounding to the nearest whole number
A pencil is $14$ cm long, to the nearest centimetre. Write the error interval for its length $l$.
@step The unit is $1$ cm, so half a unit is $0.5$ cm.
@step Lower bound: $14 - 0.5 = 13.5$. Upper bound: $14 + 0.5 = 14.5$.
@step $13.5$ rounds up to $14$, so it is included; $14.5$ rounds up to $15$, so it is not.
@answer $13.5 \le l < 14.5$
:::

:::example Rounding to a decimal place
The mass of a parcel is $3.7$ kg, to $1$ decimal place. Write the error interval for its mass $m$.
@step The unit is $0.1$ kg, so half a unit is $0.05$ kg.
@step $3.7 - 0.05 = 3.65$ and $3.7 + 0.05 = 3.75$.
@answer $3.65 \le m < 3.75$
:::

:::tip Significant figures
For significant figures, find the place value of the last significant figure first. $340$ to $2$ significant figures is rounded to the nearest $10$, so its error interval is $335 \le x < 345$. $0.052$ to $2$ significant figures is rounded to the nearest $0.001$, so it is $0.0515 \le x < 0.0525$.
:::

## Error intervals from truncation

:::definition Truncation
To **truncate** a number is to cut off its digits after a certain place, without rounding. $7.89$ truncated to $1$ decimal place is $7.8$.
:::

Every number from $7.8$ up to (but not including) $7.9$ truncates to $7.8$, so the error interval of a truncated number starts at the number itself and goes up by a whole unit.

:::example Truncating
A calculator truncates a number $x$ to $2$ decimal places and shows $4.25$. Write the error interval for $x$.
@step Any number from $4.25$ up to $4.26$ truncates to $4.25$: for example $4.2599$ does.
@step $4.26$ itself truncates to $4.26$, so it is not included.
@answer $4.25 \le x < 4.26$
:::

:::mistake Mixing up rounding and truncation
If $x$ is $4.25$ to $2$ decimal places by **rounding**, then $4.245 \le x < 4.255$. By **truncation**, $4.25 \le x < 4.26$. Read the question carefully to see which one it is.
:::

:::summary
- An error interval $a \le x < b$ gives every value a rounded or truncated number could have had.
- Rounding: go half a unit below and half a unit above the number.
- Truncation: start at the number and go one whole unit above it.
- The lower bound is included ($\le$); the upper bound is not ($<$).
:::
