A coach wants to know how far the students in a class can jump. One jump tells the coach very little; the jumps of the whole class tell much more, because they show what is typical and how much the students differ. Statistics starts with a question like this one, whose answers vary.

## Statistical questions

:::definition Statistical question
A **statistical question** is a question that expects answers that vary, so we answer it by collecting data: many values, not one fact.
:::

"How many hours do the students in my class sleep on a school night?" is a statistical question: each student gives a different answer, and we would look at all of them. "How many hours did I sleep last night?" is not: it has one answer.

:::example Is it a statistical question?
Decide which of these are statistical questions: (a) How tall is the school's flagpole? (b) How tall are the students in Grade 6? (c) How many pages are in each book on this shelf?
@step (a) The flagpole has one height, so the answer is a single fact. Not statistical.
@step (b) Each student has a different height, so the answers vary. Statistical.
@step (c) Each book has its own number of pages, so the answers vary. Statistical.
@answer (b) and (c) are statistical questions; (a) is not.
:::

:::

## Dot plots

A **dot plot** shows each value as a dot above a number line. Equal values stack up, so the tallest stack is the mode, and the shape of the dots shows where the data bunch together and how far they spread.

:::figure
{"type":"dotPlot","values":[1,2,2,2,3,3,3,3,3,4,4,4,5,5,7],"min":0,"max":8,"label":"Number of pets"}
:::

The dot plot above shows how many pets each of $15$ students has. Most students have $2$ to $4$ pets, the most common answer is $3$, and one student, with $7$ pets, is far from the others.

:::definition Distribution
The **distribution** of a data set is how its values are spread out: where the centre is, how widely the values spread, and the overall shape.
:::

:::example Reading a dot plot
Use the dot plot of pets above. Find the mode, the median and the range.
@step The tallest stack is at $3$, with $5$ dots, so the mode is $3$ pets.
@step The dots from left to right are the values in order. There are $15$ of them, so the median is value number $8$. Counting along: $1$, then three $2$s (values $2$ to $4$), then five $3$s (values $5$ to $9$). Value number $8$ is $3$.
@step The range is the greatest value minus the least: $7 - 1 = 6$.
@answer Mode $3$ pets, median $3$ pets, range $6$ pets.
:::

:::mistake Counting the stacks, not the dots
The number of values is the number of **dots**, not the number of stacks. In the plot above there are $6$ stacks but $15$ values.
:::

:::tip The mean from a dot plot
To find the mean, multiply each value by the number of dots above it, add the results and divide by the number of dots. For the pets: $(1 + 3 \times 2 + 5 \times 3 + 3 \times 4 + 2 \times 5 + 7) \div 15 = 51 \div 15 = 3.4$.
:::

:::check mx-dot-plot-read 3
:::

:::summary
- A statistical question expects answers that vary; we answer it with data.
- A dot plot shows each value as a dot above a number line, so the shape of the data is easy to see.
- The tallest stack is the mode. Reading the dots from left to right gives the values in order, for the median.
- Count the dots, not the stacks, to know how many values there are.
:::
