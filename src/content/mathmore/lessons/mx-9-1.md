If one pen costs the same as every other, then twice as many pens cost twice as much. If a job is shared by more people, it takes less time. These are the two kinds of proportion, and each one can be written as a rule with a single constant.

## Direct proportion

:::definition Directly proportional
$y$ is **directly proportional** to $x$, written $y \propto x$, when $y = kx$ for a fixed number $k$, the **constant of proportionality**. When $x$ is doubled, $y$ is doubled too. A quantity can also be proportional to a power or root of another: $y \propto x^2$ means $y = kx^2$, and $y \propto \sqrt{x}$ means $y = k\sqrt{x}$.
:::

We always use the same three steps: write the rule with $k$, use the pair of values we are given to find $k$, and then use the rule.

:::example A spring
The extension $e$ cm of a spring is directly proportional to the mass $m$ kg hung on it. When $m = 4$, $e = 10$. Find $e$ when $m = 7$.
@step $e = km$
@step $10 = k \times 4$, so $k = 10 \div 4 = 2.5$.
@step $e = 2.5m$, so when $m = 7$, $e = 2.5 \times 7 = 17.5$.
@answer The extension is $17.5$ cm.
:::

:::example Proportional to a square
The distance $d$ metres a stone falls is directly proportional to the square of the time $t$ seconds. When $t = 2$, $d = 20$. Find $d$ when $t = 5$.
@step $d = kt^2$
@step $20 = k \times 2^2 = 4k$, so $k = 5$.
@step $d = 5t^2 = 5 \times 5^2 = 125$
@answer The stone falls $125$ m.
:::

## Inverse proportion

:::definition Inversely proportional
$y$ is **inversely proportional** to $x$, written $y \propto \dfrac{1}{x}$, when $y = \dfrac{k}{x}$. When $x$ is doubled, $y$ is halved, so $x \times y$ always equals $k$.
:::

:::example Painters
The time $t$ hours it takes to paint a hall is inversely proportional to the number of painters $n$. Three painters take $8$ hours. How long do $4$ painters take?
@step $t = \dfrac{k}{n}$
@step $8 = \dfrac{k}{3}$, so $k = 8 \times 3 = 24$.
@step $t = \dfrac{24}{4} = 6$
@answer Four painters take $6$ hours.
:::

## Recognizing the graphs

The graph of $y = kx$ is a straight line through the origin. The graph of $y = \dfrac{k}{x}$ is a curve that falls steeply and then levels out, never touching either axis.

:::mistake Inverse is not "goes down by the same amount"
In inverse proportion $y$ is **divided** as $x$ is multiplied. Going from $3$ painters to $6$ halves the time; it does not take $3$ hours off it.

:::summary
- $y \propto x$ means $y = kx$; $y \propto x^2$ means $y = kx^2$, and so on.
- $y \propto \dfrac{1}{x}$ means $y = \dfrac{k}{x}$.
- Write the rule, use one pair of values to find $k$, then use the rule.
- Direct proportion gives a straight line through the origin; inverse proportion gives a curve that never meets the axes.
:::
