Some fractions make decimals that stop, like $\tfrac{3}{8} = 0.375$. Others make decimals that go on for ever in a repeating pattern, like $\tfrac{1}{3} = 0.333\ldots$. Every one of these repeating decimals is a fraction, and algebra finds which one.

## Recurring decimals

:::definition Recurring decimal
A **recurring decimal** has a digit, or a block of digits, that repeats for ever. Dots are put over the first and last digits of the **repeating block**:
$$0.\dot{3} = 0.333\ldots \qquad 0.1\dot{6} = 0.1666\ldots \qquad 0.\dot{2}\dot{7} = 0.272727\ldots \qquad 0.\dot{1}4\dot{2} = 0.142142\ldots$$
A decimal that stops is a **terminating decimal**.
:::

To write a fraction as a decimal, divide the numerator by the denominator. When a remainder comes round for the second time, the digits start repeating.

:::example A fraction as a recurring decimal
Write $\tfrac{5}{11}$ as a recurring decimal.
@step $5 \div 11 = 0.454545\ldots$: the remainders go $5, 6, 5, 6, \ldots$
@step The block $45$ repeats, starting straight after the point.
@answer $\tfrac{5}{11} = 0.\dot{4}\dot{5}$
:::

:::tip Which fractions terminate?
Write the fraction in its lowest terms and break the denominator into primes. If the only primes are $2$ and $5$, the decimal terminates (since $10 = 2 \times 5$). Any other prime makes it recur: $\tfrac{7}{40}$ terminates because $40 = 2^3 \times 5$, but $\tfrac{7}{30}$ recurs because $30 = 2 \times 3 \times 5$.
:::

:::

## Recurring decimals as fractions

Multiply the decimal by a power of ten that moves the point past one repeating block. Subtracting the original number then cancels all the repeating digits.

:::example A block of two digits
Write $0.\dot{2}\dot{7}$ as a fraction in its lowest terms.
@step Let $x = 0.272727\ldots$
@step The block has $2$ digits, so multiply by $100$: $100x = 27.272727\ldots$
@step Subtract: $100x - x = 27$, so $99x = 27$.
@answer $x = \tfrac{27}{99} = \tfrac{3}{11}$
:::

:::check mx-recurring-to-fraction 1
:::

When some digits come before the repeating block, first move the point to the start of the block, then past one block.

:::example A digit before the block
Write $0.1\dot{6}$ as a fraction in its lowest terms.
@step Let $x = 0.1666\ldots$
@step $10x = 1.666\ldots$ and $100x = 16.666\ldots$
@step Subtract: $100x - 10x = 16 - 1$, so $90x = 15$.
@answer $x = \tfrac{15}{90} = \tfrac{1}{6}$
:::

:::mistake Multiplying by the wrong power of ten
For $0.\dot{2}\dot{7}$, multiplying by $10$ gives $2.7272\ldots$, whose digits do not line up with $0.2727\ldots$, so they do not cancel. Use $10^{n}$, where $n$ is the number of digits in the repeating block.
:::

:::check mx-recurring-to-fraction 2
:::

:::check mx-recurring-to-fraction 3
:::

:::summary
- Dots mark the first and last digits of the repeating block.
- A fraction in its lowest terms terminates only if its denominator has no prime factors other than $2$ and $5$.
- To change a recurring decimal to a fraction: let $x$ be the decimal, multiply to line up the repeating digits, subtract, and solve for $x$.
:::
