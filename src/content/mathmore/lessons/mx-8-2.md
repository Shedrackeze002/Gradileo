Some equations, like $x^3 + 2x - 9 = 0$, cannot be solved by factorizing or with a formula we know. We can still find their solutions as accurately as we like: first by trapping a solution between two numbers, and then by iteration, repeating one calculation until the answer settles.

## Finding a solution by a change of sign

:::definition Change of sign
If $f(a)$ and $f(b)$ have opposite signs (one negative, one positive), then the graph of $y = f(x)$ crosses the $x$-axis between $x = a$ and $x = b$, as long as the graph has no breaks there. So the equation $f(x) = 0$ has a solution between $a$ and $b$. This is the **change of sign** method.
:::

:::example Showing that a solution lies between two values
Show that $x^3 + 2x - 9 = 0$ has a solution between $x = 1$ and $x = 2$.
@step Let $f(x) = x^3 + 2x - 9$.
@step $f(1) = 1 + 2 - 9 = -6$ and $f(2) = 8 + 4 - 9 = 3$.
@answer $f(1)$ is negative and $f(2)$ is positive. There is a change of sign, so there is a solution between $1$ and $2$.
:::

## Rearranging for iteration

:::definition Iteration
**Iteration** means repeating a process, each time using the last answer. An **iteration formula**, such as $x_{n+1} = \sqrt[3]{9 - 2x_n}$, turns one estimate $x_n$ into the next one, $x_{n+1}$. Starting from $x_0$, it gives $x_1$, then $x_2$, and so on.
:::

We get an iteration formula by rearranging the equation into the form $x = \ldots$:
$$x^3 + 2x - 9 = 0 \quad\Rightarrow\quad x^3 = 9 - 2x \quad\Rightarrow\quad x = \sqrt[3]{9 - 2x}$$
Then we write $x_{n+1}$ on the left and $x_n$ on the right.

:::check mx-sign-change 3
:::

:::example Using an iteration formula
Use $x_{n+1} = \sqrt[3]{9 - 2x_n}$ with $x_0 = 2$ to find a solution of $x^3 + 2x - 9 = 0$ to 2 decimal places.
@step $x_1 = \sqrt[3]{9 - 2(2)} = \sqrt[3]{5} = 1.709976\ldots$
@step $x_2 = \sqrt[3]{9 - 2(1.709976\ldots)} = 1.773697\ldots$
@step $x_3 = 1.760089\ldots$, $x_4 = 1.763013\ldots$, $x_5 = 1.762386\ldots$
@step $x_4$ and $x_5$ both round to $1.76$.
@answer The solution is $x = 1.76$ to 2 decimal places.
:::

:::tip Use the ANS key
Type $2$ and press equals. Then type the formula with ANS in place of $x_n$: $\sqrt[3]{9 - 2 \times \text{ANS}}$. Each press of equals gives the next value, with every digit kept.
:::

:::mistake Rounding as you go
Rounding $x_1$ to $1.71$ before working out $x_2$ adds an error at every step. Keep every digit, and round only the answer you write down.
:::

:::summary
- If $f(a)$ and $f(b)$ have opposite signs, $f(x) = 0$ has a solution between $a$ and $b$.
- Rearrange the equation into the form $x = \ldots$ to make an iteration formula $x_{n+1} = \ldots x_n \ldots$
- Start from $x_0$ and keep substituting each answer back in, keeping every digit.
- Stop when two answers in a row round to the same value; that value is the solution to that accuracy.
:::
