A temperature of $-8$ °C and a temperature of $8$ °C are on opposite sides of zero, but they are the same number of degrees away from it. Absolute value is the idea that measures that distance.

## Opposites

:::definition Opposite (additive inverse)
The **opposite** of a number is the number that is the same distance from zero on the other side of the number line. A number and its opposite add to zero, so the opposite is also called the **additive inverse**. The opposite of $6$ is $-6$, the opposite of $-2.5$ is $2.5$, and the opposite of $0$ is $0$.
:::

## Absolute value

:::definition Absolute value
The **absolute value** of a number is its distance from zero on the number line. We write it with two vertical bars: $|x|$. A distance is never negative, so an absolute value is never negative.
$$|7| = 7 \qquad |-7| = 7 \qquad |0| = 0$$
:::

Here we see that $-7$ and $7$ are both $7$ units from zero, so they have the same absolute value.

:::example Finding absolute values
Find $|-4.5|$ and $\left|\dfrac{2}{3}\right|$.
@step $-4.5$ is $4.5$ units from zero, so $|-4.5| = 4.5$.
@step $\dfrac{2}{3}$ is already positive, so $\left|\dfrac{2}{3}\right| = \dfrac{2}{3}$.
@answer $|-4.5| = 4.5$ and $\left|\dfrac{2}{3}\right| = \dfrac{2}{3}$
:::

Every positive distance belongs to two numbers, one on each side of zero. The two numbers with an absolute value of $9$ are $9$ and $-9$.

:::check mx-absolute-value 2
:::

:::example Absolute value in a calculation
Evaluate $|3 - 10| + |-2|$.
@step The bars work like brackets: work out the inside first. $3 - 10 = -7$
@step Take each absolute value: $|-7| = 7$ and $|-2| = 2$
@step Add: $7 + 2 = 9$
@answer $9$
:::

:::mistake Making each number positive first
$|3 - 10|$ is not $3 + 10$. Work out what is inside the bars first, and take the absolute value of the result: $|3 - 10| = |-7| = 7$.
:::

## Comparing and ordering signed numbers

On a number line, numbers get greater as we move to the right. For two positive numbers, the one with the greater absolute value is greater. For two negative numbers it is the other way around: the one with the greater absolute value is further left, so it is the smaller number.

:::example Comparing two negative numbers
Which is greater, $-3.2$ or $-3.8$?
@step $|-3.2| = 3.2$ and $|-3.8| = 3.8$, so $-3.8$ is further from zero.
@step Both are negative, so the one further from zero is further left.
@answer $-3.2 > -3.8$
:::

:::tip Ordering a mixed list
Sort the negatives first, from the greatest absolute value to the least, then zero, then the positives from least to greatest. Writing fractions as decimals makes the comparison easier: $-\dfrac{3}{4} = -0.75$.
:::

:::summary
- The opposite of a number is the same distance from zero on the other side. A number and its opposite add to zero.
- $|x|$ is the distance of $x$ from zero, so it is never negative.
- Two numbers share each positive absolute value: $|9| = |-9| = 9$.
- Work out what is inside the bars before taking the absolute value.
- Of two negative numbers, the one with the greater absolute value is the smaller number.
:::
