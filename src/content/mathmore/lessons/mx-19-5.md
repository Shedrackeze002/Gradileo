A fraction such as $\dfrac{5x + 1}{(x - 1)(x + 1)}$ has no obvious integral. Split into partial fractions, though, each part integrates to a logarithm.

## Splitting and integrating

:::definition Integrating linear fractions
$$\int \frac{1}{x - a}\,dx = \ln|x - a| + C, \qquad \int \frac{1}{ax + b}\,dx = \frac{1}{a}\ln|ax + b| + C.$$
To integrate a fraction whose denominator has linear factors, first write it in partial fractions.
:::

:::example Partial fractions, then logs
Find $\displaystyle\int_2^3 \dfrac{5x + 1}{(x - 1)(x + 1)}\,dx$.
@step $5x + 1 \equiv A(x + 1) + B(x - 1)$. Putting $x = 1$ gives $A = 3$, and $x = -1$ gives $B = 2$.
@step $\displaystyle\int_2^3 \left(\frac{3}{x - 1} + \frac{2}{x + 1}\right) dx = \Big[3\ln|x - 1| + 2\ln|x + 1|\Big]_2^3 = 3\ln 2 + 2\ln\tfrac{4}{3}$
@answer $\approx 2.65$
:::

:::mistake Divide by the coefficient of x
$\displaystyle\int \frac{6}{2x + 1}\,dx = 3\ln|2x + 1| + C$, not $6\ln|2x + 1|$: differentiating $\ln|2x + 1|$ gives $\dfrac{2}{2x + 1}$, so we divide by $2$.

## One logarithm

Exam questions often ask for the answer as $\ln K$. Use $n\ln a = \ln a^n$, $\ln a + \ln b = \ln ab$ and $\ln a - \ln b = \ln\dfrac{a}{b}$. In the example, $3\ln 2 + 2\ln\tfrac{4}{3} = \ln 8 + \ln\tfrac{16}{9} = \ln\tfrac{128}{9}$.

:::tip Keep the modulus
Write $\ln|x - a|$. Inside the limits of a definite integral both values of $x - a$ have the same sign, so the modulus just makes each one positive.
:::

- Split into partial fractions, then use $\displaystyle\int \frac{1}{ax + b}\,dx = \frac{1}{a}\ln|ax + b| + C$.
- Combine logarithms with $n\ln a = \ln a^n$, $\ln a + \ln b = \ln ab$ and $\ln a - \ln b = \ln\dfrac{a}{b}$.
:::
