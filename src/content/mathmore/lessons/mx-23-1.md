We count in tens because we have ten fingers, but nothing forces us to. A computer counts in twos, and a clock counts minutes in sixties. The same number can be written in any base, and only the place values change.

## What a base is

:::definition Number base
The **base** of a number system is the number of digits it uses, and the size of each group when we count. In **base ten** the digits are $0$ to $9$ and the place values are $1, 10, 100, 1000, \ldots$, the powers of ten. In **base two** (binary) the digits are $0$ and $1$ and the place values are $1, 2, 4, 8, \ldots$, the powers of two. We show the base with a small word or number after the numeral: $1011_{\text{two}}$.
:::

A numeral in base $b$ only uses the digits $0$ to $b - 1$. So $1011_{\text{two}}$ is a base two numeral, but $1021_{\text{two}}$ cannot be, because base two has no digit $2$.

## From another base to base ten

We multiply each digit by its place value and add.

:::example Base two to base ten
Write $1011_{\text{two}}$ in base ten.
@step The place values from the right are $1, 2, 4, 8$.
@step $1011_{\text{two}} = 1 \times 8 + 0 \times 4 + 1 \times 2 + 1 \times 1$
@answer $1011_{\text{two}} = 11_{\text{ten}}$
:::

## From base ten to another base

We divide by the base again and again and keep the remainders.

:::example Base ten to base five
Write $89$ in base five.
@step $89 \div 5 = 17$ remainder $4$
@step $17 \div 5 = 3$ remainder $2$
@step $3 \div 5 = 0$ remainder $3$
@answer Reading the remainders from the last to the first, $89 = 324_{\text{five}}$.
:::

We can check: $3 \times 25 + 2 \times 5 + 4 = 75 + 10 + 4 = 89$.

:::mistake Read the remainders upwards
The first remainder is the units digit, so it is the last digit of the answer. Reading the remainders downwards gives $423_{\text{five}}$, which is $113$, not $89$.
:::

:::check mx-base-convert 2
:::

To change between two bases that are not ten, we go through base ten: first to base ten, then to the new base.

:::check mx-base-convert 3
:::

## Calculating in another base

Column addition works in any base. The only change is when we carry: in base $b$, a column that reaches $b$ carries $1$ to the next column.

:::example Adding in base two
Work out $1011_{\text{two}} + 110_{\text{two}}$.
@step Units: $1 + 0 = 1$. Write $1$.
@step Twos: $1 + 1 = 2 = 10_{\text{two}}$. Write $0$, carry $1$.
@step Fours: $0 + 1 + 1 = 2$. Write $0$, carry $1$.
@step Eights: $1 + 1 = 2$. Write $0$, carry $1$.
@answer $1011_{\text{two}} + 110_{\text{two}} = 10001_{\text{two}}$
:::

In base ten this is $11 + 6 = 17$, and $10001_{\text{two}} = 16 + 1 = 17$, so the answer checks.

:::check mx-base-arithmetic 1
:::

When we subtract and need to borrow, we borrow one group of the base. In base five, a borrowed $1$ is worth $5$ in the column to its right.

:::check mx-base-arithmetic 2
:::

:::tip A safe method
For any calculation in another base, we can change the numbers to base ten, calculate, and change the answer back. It is slower than working in columns, but it is a good check.
:::

:::check mx-base-arithmetic 3
:::

:::summary
- In base $b$ the digits are $0$ to $b - 1$, and the place values are the powers of $b$.
- To change to base ten, multiply each digit by its place value and add.
- To change from base ten, divide by the base again and again and read the remainders from the last to the first.
- In column work in base $b$, carry or borrow in groups of $b$.
:::
