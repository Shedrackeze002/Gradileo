A vending machine is predictable: press the same button and the same drink comes out every time. That predictability is what turns a relation between two sets of numbers into a function.

## Relations

:::definition Relation
A **relation** is a set of pairings between two sets of values. Each pairing matches an **input** with an **output**, and we often write it as an ordered pair (input, output). A relation can be shown as a set of ordered pairs, a table, an arrow diagram, a graph or a rule.
:::

## Functions

:::definition Function
A **function** is a relation in which every input is paired with **exactly one** output. Knowing the input is enough to know the output for certain.
:::

Here we see two arrow diagrams. In the first, each input has one arrow leaving it, so the relation is a function. In the second, the input $2$ has two arrows, so that relation is not a function.

:::example Testing a set of ordered pairs
Is $\{(1, 4),\ (2, 7),\ (3, 7),\ (1, 9)\}$ a function?
@step Look for an input that appears more than once: the input $1$ appears twice.
@step It is paired with two different outputs, $4$ and $9$.
@answer The relation is not a function.
:::

:::mistake Thinking outputs cannot repeat
Two different inputs are allowed to share an output. In the first arrow diagram, the inputs $2$ and $3$ both give $7$, and it is still a function. Only an input with two different outputs breaks the rule.
:::

:::

:::check mx-function-or-not 2
:::

On a graph, the input is the $x$-coordinate and the output is the $y$-coordinate. Two points directly above one another share an input but have different outputs. This gives a quick visual check.

:::tip The vertical line test
Imagine sliding a vertical line across the graph. If the line ever passes through more than one point of the graph, one input has more than one output, and the relation is not a function.
:::

:::

## Inputs and outputs

Because a function gives exactly one output for each input, we can look that output up in a table, or work it out from the rule.

:::example Using a rule
A function has the rule: multiply the input by $4$, then subtract $3$. Find the output when the input is $5$.
@step $4 \times 5 = 20$
@step $20 - 3 = 17$
@answer The output is $17$.
:::

:::check mx-function-input-output 1
:::

:::check mx-function-input-output 2
:::

To go from an output back to the input, undo the steps of the rule in reverse order.

:::example Working backwards
The same function gives an output of $25$. Find the input.
@step Undo "subtract $3$": $25 + 3 = 28$
@step Undo "multiply by $4$": $28 \div 4 = 7$
@answer The input is $7$. Check: $4 \times 7 - 3 = 25$.
:::

:::check mx-function-input-output 3
:::

:::summary
- A relation pairs inputs with outputs. It can be shown as ordered pairs, a table, an arrow diagram, a graph or a rule.
- A function is a relation in which each input has exactly one output.
- Outputs may repeat, but an input with two different outputs means the relation is not a function.
- Vertical line test: a vertical line that meets a graph more than once shows it is not a function.
- Follow the rule to find an output, and undo the steps in reverse to find an input.
:::
