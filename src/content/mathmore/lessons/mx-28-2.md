If we roll a dice many times and average the scores, the average settles down close to one number. That long-run average is the expected value of the random variable.

## The expected value

:::definition Expected value
The **expected value** $E(X)$ of a discrete random variable $X$ is the mean of its distribution, the average value of $X$ over a very large number of trials. It is found by multiplying each value by its probability and adding:
$$E(X) = \sum x\,P(X = x)$$
:::

:::example A fair dice
Find the expected score when a fair six-sided dice is rolled.
@step Each score from $1$ to $6$ has probability $\dfrac{1}{6}$.
@step $E(X) = 1 \times \dfrac{1}{6} + 2 \times \dfrac{1}{6} + \dots + 6 \times \dfrac{1}{6} = \dfrac{21}{6}$
@answer $3.5$
:::

The expected value does not have to be a value that $X$ can take. Nobody ever rolls $3.5$, but $3.5$ is the long-run average.

:::example From a table
$X$ takes the values $1$, $2$, $5$ with probabilities $0.5$, $0.3$, $0.2$. Find $E(X)$.
@step $E(X) = 1 \times 0.5 + 2 \times 0.3 + 5 \times 0.2$
@step $= 0.5 + 0.6 + 1$
@answer $2.1$
:::

When a probability is unknown, we first use the fact that all the probabilities add up to $1$.

:::check mx-expected-value 2
:::

:::example Two unknowns
$X$ takes the values $1$, $2$, $3$ with probabilities $0.2$, $p$, $q$, and $E(X) = 2.3$. Find $p$ and $q$.
@step The probabilities add up to $1$: $p + q = 0.8$.
@step $E(X)$: $0.2 + 2p + 3q = 2.3$, so $2p + 3q = 2.1$.
@step From the first equation, $2p + 2q = 1.6$. Subtracting gives $q = 0.5$, so $p = 0.3$.
@answer $p = 0.3$ and $q = 0.5$
:::

## Expected numbers and fair games

If an event has probability $p$ each time and we repeat the trial $n$ times, the **expected number** of times it happens is $np$.

:::example Expected number
The probability that a seed germinates is $0.8$. Of $250$ seeds, how many are expected to germinate?
@step $np = 250 \times 0.8$
@answer $200$
:::

:::check mx-expected-gain 1
:::

In a game of chance, the expected **gain** is the expected winnings minus the cost of playing. A game is **fair** when the expected gain is $0$.

:::example Is the game fair?
A game costs \$2 to play. A player wins \$10 with probability $0.1$ and \$5 with probability $0.2$, and otherwise wins nothing. Find the expected gain.
@step Expected winnings $= 10 \times 0.1 + 5 \times 0.2 = 2$ dollars
@step Expected gain $= 2 - 2 = 0$ dollars
@answer \$0, so the game is fair
:::

:::mistake Forgetting the cost
The expected winnings are not the expected gain. Subtract what it costs to play, which the player pays whether they win or not.
:::

:::summary
- $E(X) = \sum x\,P(X = x)$ is the long-run average of $X$.
- The probabilities add up to $1$; with $E(X)$ this gives equations for unknown probabilities.
- The expected number of successes in $n$ trials is $np$, and a game is fair when the expected gain is $0$.
:::
