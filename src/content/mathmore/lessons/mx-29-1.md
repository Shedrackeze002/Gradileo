Many areas under curves cannot be found exactly by integration, and sometimes we only have a table of values. The trapezium rule is one way to estimate them. The mid-ordinate rule is another, and it uses rectangles instead of trapezia.

## The mid-ordinate rule

:::definition Mid-ordinate rule
The **mid-ordinate rule** estimates the area under a curve by splitting it into $n$ strips of equal width $h$ and drawing a rectangle on each strip whose height is the value of $y$ at the **midpoint** of the strip (its mid-ordinate):
$$\int_a^b y\,dx \approx h\left(y_1 + y_2 + \dots + y_n\right), \qquad h = \frac{b - a}{n}$$
where $y_1, y_2, \dots, y_n$ are the mid-ordinates.
:::

## Setting up the strips

With a formula for the curve, we first find $h$ and the midpoints, then the mid-ordinates.

:::example From a formula
Use the mid-ordinate rule with $4$ strips to estimate $\displaystyle\int_0^4 (x^2 + 1)\,dx$.
@step $h = \dfrac{4 - 0}{4} = 1$, and the midpoints are $x = 0.5, 1.5, 2.5, 3.5$.
@step Mid-ordinates: $1.25$, $3.25$, $7.25$, $13.25$
@step Area $\approx 1 \times (1.25 + 3.25 + 7.25 + 13.25)$
@answer $25$
:::

:::mistake Using the ends of the strips
The mid-ordinate rule uses the $y$ values at the middle of each strip, not at its ends. With $n$ strips there are exactly $n$ mid-ordinates, while the trapezium rule uses $n + 1$ ordinates.
:::

## How accurate is it?

In the last example, the exact value is $\left[\dfrac{x^3}{3} + x\right]_0^4 = \dfrac{76}{3} \approx 25.33$, so the estimate of $25$ has a percentage error of
$$\frac{25.33 - 25}{25.33} \times 100 \approx 1.3\%$$
More strips give a better estimate.

:::check mx-mid-ordinate-error 2
:::

Whether the rule gives too much or too little depends on how the curve bends. The top of each rectangle can be tilted about its midpoint into the tangent there without changing its area. A curve that bends upwards (convex) lies above its tangents, so the mid-ordinate rule gives an **underestimate**. A curve that bends downwards (concave) lies below them, so it gives an **overestimate**. The trapezium rule does the opposite in each case.

:::tip Opposite errors
For a curve that bends the same way all along, the true area lies between the mid-ordinate estimate and the trapezium estimate.
:::

:::check mx-mid-ordinate-error 3
:::

:::summary
- Mid-ordinate rule: area $\approx h(y_1 + \dots + y_n)$ with the $y$ values at the midpoints of the strips.
- $h = \dfrac{b - a}{n}$, and more strips give a better estimate.
- It underestimates for a curve that bends upwards and overestimates for one that bends downwards.
:::
