How can we be sure that $n^2 + n$ is even for every integer $n$, when there are infinitely many integers to check? Every integer is either even or odd, so checking those two cases checks them all.

## Proof by exhaustion

:::definition Proof by exhaustion
A **proof by exhaustion** splits a statement into a finite number of cases that between them cover every possibility, and proves the statement in each case. A **counterexample** is a single example for which a statement is false; one counterexample is enough to **disprove** a statement.
:::

Useful sets of cases come from remainders: every integer is $2k$ or $2k + 1$ (even or odd), or $3k$, $3k + 1$ or $3k + 2$, for an integer $k$.

:::example Two cases
Prove that $n^2 + n$ is even for every integer $n$.
@step If $n$ is even, $n = 2k$: $n^2 + n = 4k^2 + 2k = 2(2k^2 + k)$, which is even.
@step If $n$ is odd, $n = 2k + 1$: $n^2 + n = 4k^2 + 4k + 1 + 2k + 1 = 2(2k^2 + 3k + 1)$, which is even.
@answer Every integer is even or odd, so $n^2 + n$ is always even.
:::

:::mistake Examples are not a proof
Checking $n = 1, 2, 3, \ldots, 100$ does not prove a statement about **every** integer, however many values you try. Only cases that cover every possibility make a proof.
:::

## Disproof by counterexample

To show a statement is false, one example is enough.

:::example A counterexample
Show that “$n^2 - n + 11$ is prime for every positive integer $n$” is false.
@step For $n = 1, 2, \ldots, 10$ the values ($11, 13, 17, \ldots, 101$) are all prime.
@step For $n = 11$: $11^2 - 11 + 11 = 121 = 11^2$.
@answer $121$ is not prime, so $n = 11$ is a counterexample and the statement is false.
:::

:::tip Choose cases that make the algebra work
For a question about multiples of $3$, use $n = 3k$, $3k + 1$ and $3k + 2$; for even and odd, use $2k$ and $2k + 1$. Then expand and take out the factor you need.
:::

:::

:::summary
- Proof by exhaustion proves every case of a set of cases that covers all possibilities.
- Cases often come from remainders: $2k$ and $2k + 1$, or $3k$, $3k + 1$ and $3k + 2$.
- A single counterexample disproves a statement; any number of examples cannot prove one.
:::
