In a linear sequence, like $5,\ 8,\ 11,\ 14,\ \ldots$, the terms go up by the same amount each time. In the sequence of square numbers, $1,\ 4,\ 9,\ 16,\ \ldots$, the gaps grow: $3,\ 5,\ 7,\ \ldots$ But the gaps grow by the same amount each time. Sequences like this are quadratic.

## Second differences

:::definition Quadratic sequence
A **quadratic sequence** is a sequence whose $n$th term has an $n^2$ term and no higher power, such as $n^2 + 3$ or $2n^2 - n + 4$. The differences between its terms (the **first differences**) change, but the differences between those (the **second differences**) are all the same.
:::

:::example Continuing a quadratic sequence
Find the next term of $3,\ 6,\ 11,\ 18,\ 27,\ \ldots$
@step First differences: $3,\ 5,\ 7,\ 9$.
@step Second differences: $2,\ 2,\ 2$. They are the same, so the sequence is quadratic.
@step The next first difference is $9 + 2 = 11$.
@answer The next term is $27 + 11 = 38$.
:::

## Finding the nth term

The $n$th term is $an^2 + bn + c$. The second difference is always $2a$, so the number in front of $n^2$ is **half the second difference**. Subtracting $an^2$ from each term leaves a linear sequence, whose $n$th term gives $bn + c$.

:::example The nth term
Find the $n$th term of $4,\ 13,\ 26,\ 43,\ 64,\ \ldots$
@step First differences: $9,\ 13,\ 17,\ 21$. Second differences: $4,\ 4,\ 4$.
@step Half of $4$ is $2$, so the sequence starts with $2n^2$: $2,\ 8,\ 18,\ 32,\ 50$.
@step Subtract: $4 - 2,\ 13 - 8,\ 26 - 18,\ 43 - 32,\ 64 - 50$ gives $2,\ 5,\ 8,\ 11,\ 14$.
@step That linear sequence goes up by $3$, and $3 \times 1 = 3$ is $1$ more than $2$, so its $n$th term is $3n - 1$.
@answer The $n$th term is $2n^2 + 3n - 1$.
:::

:::tip Check your answer
Put $n = 1$ and $n = 2$ into your expression: $2(1)^2 + 3(1) - 1 = 4$ and $2(2)^2 + 3(2) - 1 = 13$. Both match the sequence.
:::

:::mistake Using the whole second difference
If the second difference is $4$, the sequence starts with $2n^2$, not $4n^2$. The square numbers $n^2$ have a second difference of $2$, so $an^2$ has a second difference of $2a$.

## Using the nth term

With the $n$th term we can find any term without listing the ones before it, and we can find which term has a given value by solving a quadratic equation.

:::example Which term?
The $n$th term of a sequence is $n^2 + 2n - 5$. Which term is $58$?
@step $n^2 + 2n - 5 = 58$, so $n^2 + 2n - 63 = 0$.
@step Factorize: $(n + 9)(n - 7) = 0$, so $n = -9$ or $n = 7$.
@answer A term number must be positive, so $58$ is the $7$th term.
:::

:::check mx-quadratic-sequence-term 3
:::

:::summary
- In a quadratic sequence the second differences are all the same.
- The $n$th term is $an^2 + bn + c$, where $a$ is half the second difference.
- Subtract $an^2$ from each term, then find the $n$th term of the linear sequence that is left.
- To find which term has a value, set the $n$th term equal to it and solve; the term number must be a positive whole number.
:::
