A function turns inputs into outputs, so two natural questions follow: which inputs is it allowed to take, and which outputs can it produce? The answers are the domain and the range.

## Domain and range

:::definition Domain
The **domain** of a function is the set of all its inputs: every value the independent variable is allowed to take.
:::

:::definition Range
The **range** of a function is the set of all its outputs: every value the dependent variable takes as the input runs through the domain.
:::

:::example Domain and range from ordered pairs
Find the domain and the range of $\{(1, 5),\ (2, 8),\ (3, 5),\ (4, 11)\}$.
@step The inputs are the first numbers: $1, 2, 3, 4$
@step The outputs are the second numbers: $5, 8, 5, 11$. A set lists each element once.
@answer Domain: $\{1, 2, 3, 4\}$. Range: $\{5, 8, 11\}$.
:::

:::mistake Listing a repeated output twice
The domain and the range are sets, so each value is written once, usually in order from least to greatest. The range above is $\{5, 8, 11\}$, not $\{5, 8, 5, 11\}$.
:::

## Discrete and continuous

:::definition Discrete and continuous
A function is **discrete** when its domain is made of separate values with gaps between them, such as a count of people. Its graph is a set of separate points. A function is **continuous** when its domain includes every value in an interval, such as a length of time. Its graph is an unbroken line or curve.
:::

So the question to ask is whether the values *between* the ones in the table have a meaning. The cost of tickets is a function of the number of tickets, and nobody can buy $2.5$ tickets, so that function is discrete and its points are not joined. The distance a cyclist has travelled is a function of time, and $2.5$ hours is a perfectly good time, so that function is continuous and its points are joined.

:::check mx-discrete-continuous 1
:::

:::tip Counted or measured?
Quantities that are **counted** (buses, tickets, full cartons) give discrete functions. Quantities that are **measured** (time, length, mass, temperature) give continuous ones.
:::

:::

## Domain and range in context

In a real situation, the domain and the range are limited by what makes sense.

:::example A draining tank
A tank holds $60$ litres of water. It drains at $5$ litres each minute until it is empty, after $12$ minutes. The volume $V$ litres is a function of the time $t$ minutes. Describe the domain and the range.
@step The time runs from $0$ to $12$ minutes, and every moment in between makes sense: the domain is all numbers from $0$ to $12$.
@step The volume starts at $60$ and falls to $0$, passing through every value in between: the range is all numbers from $0$ to $60$.
@answer Domain: $0 \le t \le 12$. Range: $0 \le V \le 60$. The function is continuous.
:::

:::

:::check mx-discrete-continuous 3
:::

:::summary
- The domain is the set of inputs, and the range is the set of outputs.
- From ordered pairs or a table: domain = the first values, range = the second values, each written once.
- Discrete: separate inputs (counted), graphed as points that are not joined.
- Continuous: every input in an interval (measured), graphed as an unbroken line or curve.
- In context, the domain and the range are limited to the values that make sense.
:::
