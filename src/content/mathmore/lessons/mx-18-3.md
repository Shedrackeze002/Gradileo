Add a sine wave to a cosine wave of the same period and the result is another wave of that period, just taller and shifted. Writing $a\sin\theta + b\cos\theta$ as one sine makes its greatest value, and its equations, easy.

## The R sin(θ + α) form

:::definition Harmonic form
For positive $a$ and $b$,
$$a\sin\theta + b\cos\theta \equiv R\sin(\theta + \alpha), \qquad R = \sqrt{a^2 + b^2}, \quad \tan\alpha = \frac{b}{a},$$
with $R > 0$ and $\alpha$ acute. Similar forms are $R\sin(\theta - \alpha)$ and $R\cos(\theta \pm \alpha)$.
:::

Expanding $R\sin(\theta + \alpha) = R\cos\alpha\sin\theta + R\sin\alpha\cos\theta$ and comparing coefficients gives $R\cos\alpha = a$ and $R\sin\alpha = b$.

:::example Into one sine
Write $3\sin\theta + 4\cos\theta$ in the form $R\sin(\theta + \alpha)$.
@step $R\cos\alpha = 3$ and $R\sin\alpha = 4$.
@step $R = \sqrt{3^2 + 4^2} = 5$, and $\tan\alpha = \dfrac{4}{3}$, so $\alpha \approx 53.1^\circ$.
@answer $3\sin\theta + 4\cos\theta \equiv 5\sin(\theta + 53.1^\circ)$
:::

:::mistake tan α is b over a
With $R\cos\alpha = a$ and $R\sin\alpha = b$, $\tan\alpha = \dfrac{R\sin\alpha}{R\cos\alpha} = \dfrac{b}{a}$. Writing $\dfrac{a}{b}$ gives the complement of the right angle.
:::

:::check mx-r-alpha 3
:::

## Using the form

Since a sine lies between $-1$ and $1$, $R\sin(\theta + \alpha)$ lies between $-R$ and $R$. Its greatest value, $R$, is where $\theta + \alpha = 90^\circ$.

:::example Solving an equation
Solve $3\sin\theta + 4\cos\theta = 2$ for $0^\circ \le \theta < 360^\circ$.
@step $5\sin(\theta + 53.13^\circ) = 2$, so $\sin(\theta + 53.13^\circ) = 0.4$.
@step $\theta + 53.13^\circ$ lies between $53.13^\circ$ and $413.13^\circ$, so it is $180^\circ - 23.58^\circ = 156.42^\circ$ or $360^\circ + 23.58^\circ = 383.58^\circ$.
@answer $\theta \approx 103.3^\circ$ or $\theta \approx 330.4^\circ$.
:::

:::

:::check mx-r-alpha-apply 2
:::

:::tip Shift the interval
If $0^\circ \le \theta < 360^\circ$, then $\theta + \alpha$ runs from $\alpha$ to $360^\circ + \alpha$. Find every solution for $\theta + \alpha$ in that shifted interval before subtracting $\alpha$.
:::

:::

:::summary
- $a\sin\theta + b\cos\theta \equiv R\sin(\theta + \alpha)$ with $R = \sqrt{a^2 + b^2}$ and $\tan\alpha = \dfrac{b}{a}$.
- The greatest value is $R$ and the least is $-R$.
- To solve $a\sin\theta + b\cos\theta = c$, solve $\sin(\theta + \alpha) = \dfrac{c}{R}$ in the shifted interval.
:::
