Roll a dice and the score could be any of six numbers; toss three coins and the number of heads could be $0$, $1$, $2$ or $3$. A random variable gives a name to a number like this, and its probability distribution says how likely each value is.

## Probability distributions

:::definition Discrete random variable
A **random variable** $X$ is a quantity whose value depends on chance. It is **discrete** when it can take only separate values, such as whole numbers. Its **probability distribution** gives $P(X = x)$ for each value $x$, and these probabilities always add up to $1$:
$$\sum P(X = x) = 1.$$
:::

For example, this table gives the distribution of a random variable $X$, with one probability unknown.

| $x$ | $1$ | $2$ | $3$ | $4$ |
| --- | --- | --- | --- | --- |
| $P(X = x)$ | $0.1$ | $0.3$ | $k$ | $2k$ |

:::example An unknown probability
For the distribution in the table, find $k$ and $P(X \ge 3)$.
@step The probabilities add to $1$: $0.1 + 0.3 + k + 2k = 1$, so $3k = 0.6$ and $k = 0.2$.
@step $P(X \ge 3) = P(X = 3) + P(X = 4) = 0.2 + 0.4$.
@answer $k = 0.2$ and $P(X \ge 3) = 0.6$.
:::

## Probability functions

A distribution can also be given as a formula, a **probability function**, such as $P(X = x) = kx$ for $x = 1, 2, 3, 4$. Write out each probability in terms of $k$ and use the fact that they add to $1$.

:::example A probability function
$P(X = x) = kx$ for $x = 1, 2, 3, 4$. Find $k$ and $P(X > 2)$.
@step $k(1 + 2 + 3 + 4) = 10k = 1$, so $k = \dfrac{1}{10}$.
@step $P(X > 2) = P(X = 3) + P(X = 4) = \dfrac{3 + 4}{10}$.
@answer $k = \dfrac{1}{10}$ and $P(X > 2) = \dfrac{7}{10}$.
:::

:::summary
- A discrete random variable takes separate values, each with a probability.
- The probabilities of a distribution always add up to $1$; use this to find an unknown.
- A probability function gives $P(X = x)$ as a formula in $x$.
- With equally likely outcomes, $P(X = x) = \dfrac{\text{outcomes giving } x}{\text{all outcomes}}$.
:::
