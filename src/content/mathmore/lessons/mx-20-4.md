Every number we have met, from counting numbers to $\sqrt{2}$ and $\pi$, lives on the number line. Mathematicians sort these numbers into sets that sit one inside the other, and they use a compact notation to describe exactly which numbers a set contains.

## Sets of numbers

:::definition Set, element and subset
A **set** is a collection of distinct objects, which are called its **elements**. We list the elements inside braces: $\{2, 4, 6\}$. The symbol $\in$ means "is an element of", so $4 \in \{2, 4, 6\}$. Set $A$ is a **subset** of set $B$ when every element of $A$ is also an element of $B$. A set is **finite** when its elements can be counted to an end, and **infinite** when they go on forever.
:::

:::definition The real number system
The **real numbers**, $\mathbb{R}$, are all the numbers on the number line. They are organized into these sets:

- **Natural numbers**, $\mathbb{N}$: the counting numbers $1, 2, 3, \ldots$
- **Integers**, $\mathbb{Z}$: the natural numbers, their opposites and zero: $\ldots, -2, -1, 0, 1, 2, \ldots$
- **Rational numbers**, $\mathbb{Q}$: every number that can be written as a fraction $\dfrac{a}{b}$ of two integers with $b \ne 0$. As decimals they terminate or repeat.
- **Irrational numbers**: the real numbers that are not rational, such as $\sqrt{2}$ and $\pi$. As decimals they never end and never repeat.
:::

Each set sits inside the next: every natural number is an integer, every integer is rational (because $n = \dfrac{n}{1}$) and every rational number is real. The rational and irrational numbers have nothing in common, and together they make up all the real numbers.

:::example Classifying numbers
Name every set that $-5$, $0.\overline{3}$ and $\sqrt{7}$ belong to.
@step $-5$ is a negative whole number: it is an integer, so it is also rational and real. It is not a natural number.
@step $0.\overline{3} = \dfrac{1}{3}$, a fraction that is not a whole number: it is rational and real.
@step $7$ is not a perfect square, so $\sqrt{7}$ never ends and never repeats: it is irrational and real.
@answer $-5$: integer, rational, real. $0.\overline{3}$: rational, real. $\sqrt{7}$: irrational, real.
:::

## Set-builder notation

Listing works for a small set, but we cannot list every real number greater than $3$. Set-builder notation describes a set by the rule its elements follow.

:::definition Set-builder notation
**Set-builder notation** describes a set by stating a condition:
$$\{x \mid x > 3,\ x \in \mathbb{R}\}$$
We read this as "the set of all $x$ such that $x$ is greater than $3$ and $x$ is a real number". The bar $\mid$ means "such that", and the last part names the set of numbers that $x$ is drawn from.
:::

:::example Listing a set from its rule
List the elements of $\{x \mid -2 \le x < 3,\ x \in \mathbb{Z}\}$.
@step $x$ is an integer, so we only want whole numbers and their opposites.
@step $-2 \le x$ includes $-2$. $x < 3$ does not include $3$.
@answer $\{-2, -1, 0, 1, 2\}$
:::

:::check mx-set-builder 1
:::

:::tip Why the number set matters
$\{x \mid x < 4,\ x \in \mathbb{N}\}$ is the finite set $\{1, 2, 3\}$. $\{x \mid x < 4,\ x \in \mathbb{R}\}$ is infinite: it contains $3.9$, $0$, $-\sqrt{2}$ and every other real number below $4$.
:::

:::check mx-set-builder 2
:::

Set-builder notation is the natural way to write the solutions of an inequality, because an inequality usually has infinitely many solutions.

:::example The solution set of an inequality
Solve $2x + 1 \le 9$ and write the solutions in set-builder notation.
@step Subtract $1$ from both sides: $2x \le 8$
@step Divide both sides by $2$: $x \le 4$
@answer $\{x \mid x \le 4,\ x \in \mathbb{R}\}$
:::

:::check mx-set-builder 3
:::

:::summary
- $\mathbb{N}$ (natural), $\mathbb{Z}$ (integers), $\mathbb{Q}$ (rational) and $\mathbb{R}$ (real) sit one inside the next. The irrational numbers are the real numbers that are not rational.
- Rational numbers terminate or repeat as decimals. Irrational numbers do neither.
- Simplify a number before deciding which sets it belongs to.
- $\{x \mid \text{condition},\ x \in \text{set}\}$ reads "the set of all $x$ such that ...".
- $<$ and $>$ leave the end number out. $\le$ and $\ge$ include it.
:::
