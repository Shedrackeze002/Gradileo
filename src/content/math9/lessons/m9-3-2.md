A warm wind can raise the temperature in a city by 20 degrees in a few hours, and a cold snap can drop it just as fast. To track changes like these, you add and subtract rational numbers. The rules are the same ones you use for integers.

## Adding and subtracting decimals

:::note Rules for adding
- **Same signs:** add the sizes and keep the sign. $-2.4 + (-1.8) = -4.2$
- **Different signs:** subtract the sizes. Use the sign of the number with the greater size. $-3.7 + 1.6 = -2.1$
:::

:::

:::example Adding a positive to a negative
Find $-3.7 + 1.6$.
@step The signs are different. Subtract the sizes: $3.7 - 1.6 = 2.1$.
@step $-3.7$ has the greater size, so the answer is negative.
@answer $-3.7 + 1.6 = -2.1$
:::

To subtract, **add the opposite**.

:::example Subtracting a negative
Find $8.7 - (-5.5)$.
@step Add the opposite of $-5.5$: $8.7 - (-5.5) = 8.7 + 5.5$
@answer $8.7 - (-5.5) = 14.2$
:::

## Adding and subtracting fractions

Fractions need a common denominator before you add or subtract them. Then use the sign rules on the numerators.

:::example Different denominators
Find $-\frac{2}{3} + \frac{3}{4}$.
@step The common denominator is $12$: $-\frac{2}{3} = -\frac{8}{12}$ and $\frac{3}{4} = \frac{9}{12}$.
@step Add the numerators: $-8 + 9 = 1$.
@answer $-\frac{2}{3} + \frac{3}{4} = \frac{1}{12}$
:::

:::example Subtracting a negative fraction
Find $-\frac{1}{2} - \left(-\frac{5}{6}\right)$.
@step Add the opposite: $-\frac{1}{2} + \frac{5}{6}$
@step Common denominator $6$: $-\frac{3}{6} + \frac{5}{6} = \frac{2}{6}$
@answer $\frac{2}{6} = \frac{1}{3}$
:::

:::mistake Do not add the denominators
$\frac{1}{4} + \frac{1}{2}$ is **not** $\frac{2}{6}$. The denominator tells the size of the pieces, and it stays the same once the pieces match: $\frac{1}{4} + \frac{2}{4} = \frac{3}{4}$.
:::

## Mixed numbers

Write mixed numbers as improper fractions first. This keeps the signs simple.

:::example Adding mixed numbers with different signs
Find $-2\frac{1}{4} + 1\frac{2}{3}$.
@step Improper fractions: $-2\frac{1}{4} = -\frac{9}{4}$ and $1\frac{2}{3} = \frac{5}{3}$.
@step Common denominator $12$: $-\frac{27}{12} + \frac{20}{12}$
@step Add the numerators: $-27 + 20 = -7$
@answer $-2\frac{1}{4} + 1\frac{2}{3} = -\frac{7}{12}$
:::

## Solving problems with changes

A rise, a gain or a deposit is a positive change. A drop, a loss or a payment is a negative change.

:::example Temperature in Hillcrest
At 6:00 a.m. the temperature in Hillcrest was $-14.6^\circ\text{C}$. By noon it had risen $9.8$ degrees. By 9:00 p.m. it had fallen $7.3$ degrees from the noon temperature. What was the temperature at 9:00 p.m.?
@step Noon: $-14.6 + 9.8 = -4.8$
@step 9:00 p.m.: $-4.8 + (-7.3) = -12.1$
@answer The temperature at 9:00 p.m. was $-12.1^\circ\text{C}$.
:::

:::tip How much warmer?
The difference between two temperatures is warmer $-$ colder. From $-17.4^\circ\text{C}$ to $-2.9^\circ\text{C}$: $-2.9 - (-17.4) = -2.9 + 17.4 = 14.5$ degrees.
:::

:::check m9-rational-add-sub 3
:::

:::summary
- Same signs: add the sizes and keep the sign. Different signs: subtract the sizes and use the sign of the greater size.
- To subtract, add the opposite: $a - (-b) = a + b$.
- Fractions need a common denominator. Write mixed numbers as improper fractions first.
- In problems, rises and deposits are positive; drops and payments are negative.
:::
