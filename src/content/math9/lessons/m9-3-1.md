On a winter morning it might be $-12.5^\circ\text{C}$ in Riverton and $-12\frac{1}{4}$ degrees in Lakeside. Which town is colder? Numbers like these, positive and negative fractions and decimals, are all rational numbers.

## What is a rational number?

:::definition Rational number
A **rational number** is any number that can be written as a fraction $\dfrac{a}{b}$, where $a$ and $b$ are integers and $b \ne 0$.
:::

All of these are rational numbers:
- $-\frac{3}{4}$, $\frac{5}{2}$ and $-2\frac{1}{3}$ (fractions and mixed numbers)
- $0.5 = \frac{1}{2}$ and $-1.25 = -\frac{5}{4}$ (terminating decimals)
- $0.\overline{6} = \frac{2}{3}$ (repeating decimals)
- $7 = \frac{7}{1}$ and $-4 = \frac{-4}{1}$ (integers)

A negative fraction can be written three ways: $-\frac{3}{4} = \frac{-3}{4} = \frac{3}{-4}$.

:::definition Opposites
Two numbers are **opposites** if they are the same distance from $0$ on a number line but on opposite sides, like $-1.5$ and $1.5$.
:::

## Comparing two rational numbers

Numbers increase from left to right on a number line. To compare, write both numbers in the same form: both as decimals, or both as fractions with a common denominator.

:::example Comparing a fraction and a decimal
Which is greater, $-\frac{3}{4}$ or $-0.7$?
@step Write $-\frac{3}{4}$ as a decimal: $-\frac{3}{4} = -0.75$.
@step On a number line, $-0.75$ is farther left than $-0.7$, because it is farther from $0$.
@answer $-0.7 > -\frac{3}{4}$
:::

:::example Comparing two negative fractions
Compare $-\frac{2}{3}$ and $-\frac{3}{5}$.
@step Common denominator $15$: $-\frac{2}{3} = -\frac{10}{15}$ and $-\frac{3}{5} = -\frac{9}{15}$.
@step $-\frac{10}{15}$ is farther from $0$, so it is less.
@answer $-\frac{2}{3} < -\frac{3}{5}$
:::

:::mistake Bigger digits, smaller number
For negative numbers, a greater size means a **smaller** number. $-0.75 < -0.7$, even though $75$ is bigger than $70$. Think of temperatures: $-20^\circ\text{C}$ is colder than $-5^\circ\text{C}$.
:::

Back to the opening question: $-12\frac{1}{4} = -12.25$, and $-12.5 < -12.25$. It was colder in Riverton.

## Ordering rational numbers

:::example Ordering five numbers
Order from least to greatest: $0.4$, $-1\frac{1}{3}$, $\frac{1}{2}$, $-1.3$, $-\frac{3}{5}$.
@step Write each as a decimal: $0.4$, $-1\frac{1}{3} = -1.\overline{3}$, $\frac{1}{2} = 0.5$, $-1.3$, $-\frac{3}{5} = -0.6$.
@step The negatives are $-1.\overline{3}$, $-1.3$ and $-0.6$. The one farthest from $0$ is the least: $-1.\overline{3} < -1.3 < -0.6$.
@step The positives: $0.4 < 0.5$.
@answer $-1\frac{1}{3},\ -1.3,\ -\frac{3}{5},\ 0.4,\ \frac{1}{2}$
:::

:::tip Repeating decimals
$-1.\overline{3} = -1.333\ldots$, which is a little less than $-1.3$. Write out a few more digits when two decimals are close.
:::

## A number between two others

Between any two rational numbers there is always another one. To find one, write both numbers as decimals with the same number of places.

:::example Finding a number in between
Find a rational number between $-\frac{2}{3}$ and $-0.6$.
@step $-\frac{2}{3} = -0.666\ldots$ and $-0.6 = -0.600$.
@step Any decimal from $-0.66$ to $-0.61$ is between them. For example, $-0.65$.
@step Check: $-0.666\ldots < -0.65 < -0.6$
@answer $-0.65$ is one answer. There are many others.
:::

:::check m9-rational-compare 3
:::

:::summary
- A rational number can be written as $\frac{a}{b}$ with integers $a$ and $b$, $b \ne 0$. This includes integers, fractions, mixed numbers and terminating or repeating decimals.
- Opposites are the same distance from $0$ on opposite sides.
- To compare, write the numbers in the same form. For negatives, the one farther from $0$ is less.
- There is always another rational number between two rational numbers.
:::
