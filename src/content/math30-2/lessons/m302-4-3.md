How long will two pumps take to empty a flooded basement together? How many hoodies must a class sell to bring the cost per hoodie down to a target? Questions like these lead to equations with the variable in a denominator: rational equations.

## Solving by multiplying by the LCD

:::definition Rational equation
An equation that contains at least one rational expression, such as $\dfrac{3}{x} + \dfrac{1}{2x} = \dfrac{7}{4}$.
:::

The plan is always the same:

1. Write down the non-permissible values.
2. Multiply **every term** on both sides by the lowest common denominator. The fractions disappear.
3. Solve the equation that is left.
4. Check each answer against the non-permissible values.

:::example Monomial denominators
Solve $\dfrac{3}{x} + \dfrac{1}{2x} = \dfrac{7}{4}$.
@step Non-permissible value: $x \ne 0$. The LCD of $x$, $2x$ and $4$ is $4x$.
@step Multiply every term by $4x$: $12 + 2 = 7x$.
@step $14 = 7x$, so $x = 2$.
@answer $x = 2$ (it is permissible). Check: $\tfrac{3}{2} + \tfrac{1}{4} = \tfrac{7}{4}$ ✓
:::

When there is one fraction on each side, multiplying by both denominators is the same as cross-multiplying.

:::example A proportion
Solve $\dfrac{4}{x - 1} = \dfrac{6}{x + 2}$.
@step Non-permissible values: $x \ne -2,\ 1$.
@step Cross-multiply: $4(x + 2) = 6(x - 1)$, so $4x + 8 = 6x - 6$.
@step $14 = 2x$, so $x = 7$.
@answer $x = 7$
:::

## Extraneous roots

Multiplying by an expression that contains the variable can create answers that do not work in the original equation.

:::definition Extraneous root
A solution of the cleared equation that is a non-permissible value of the original equation. It must be rejected.
:::

:::example No solution
Solve $\dfrac{x}{x - 3} = 2 + \dfrac{3}{x - 3}$.
@step Non-permissible value: $x \ne 3$.
@step Multiply every term by $x - 3$: $x = 2(x - 3) + 3$, so $x = 2x - 3$ and $x = 3$.
@step But $x = 3$ makes the denominators $0$: it is extraneous.
@answer There is no solution.
:::

:::example One root survives
Solve $\dfrac{x}{x + 4} + \dfrac{2}{x - 4} = \dfrac{16}{x^2 - 16}$.
@step Factor: $x^2 - 16 = (x + 4)(x - 4)$, so $x \ne -4,\ 4$.
@step Multiply every term by $(x + 4)(x - 4)$: $x(x - 4) + 2(x + 4) = 16$.
@step Expand and collect: $x^2 - 2x - 8 = 0$, so $(x - 4)(x + 2) = 0$ and $x = 4$ or $x = -2$.
@answer $x = 4$ is extraneous, so the only solution is $x = -2$.
:::

:::mistake Skipping the check
Every algebra step can be correct and the answer still be wrong. Always compare your answers with the non-permissible values you wrote down at the start.
:::

## Work-rate problems

If a job takes 3 hours, then in 1 hour you do $\tfrac{1}{3}$ of it. Rates add when people or machines work together.

:::example Working together
Working alone, Aisha can paint a classroom in 3 h and Mateo can paint it in 6 h. How long do they take together?
@step Let $t$ be the time together. Each hour they do $\tfrac{1}{3} + \tfrac{1}{6}$ of the job, which must equal $\tfrac{1}{t}$.
@step Multiply every term of $\dfrac{1}{3} + \dfrac{1}{6} = \dfrac{1}{t}$ by $6t$: $2t + t = 6$.
@answer $t = 2$ h
:::

:::tip Check that the answer is sensible
Working together must be faster than the faster worker alone. Here $2$ h is less than $3$ h, so the answer is reasonable.
:::

## Travel and average cost

For travel, use time $= \dfrac{\text{distance}}{\text{speed}}$. For average cost, divide the total cost by the number of items.

:::example Equal travel times
In the same time that a car travels 300 km, a truck travels 250 km. The car is 15 km/h faster. Find the truck's speed.
@step Let $s$ be the truck's speed. The times are equal: $\dfrac{300}{s + 15} = \dfrac{250}{s}$, with $s \ne -15,\ 0$.
@step Cross-multiply: $300s = 250s + 3750$, so $50s = 3750$.
@answer The truck travels at 75 km/h (and the car at 90 km/h).
:::

:::example Average cost
A leadership class in Lakeside pays a fixed \$1200 to set up a hoodie order, plus \$4.50 for each hoodie. How many hoodies make the average cost \$10.50 per hoodie?
@step The average cost of $n$ hoodies is $C(n) = \dfrac{1200 + 4.5n}{n}$ dollars.
@step Solve $\dfrac{1200 + 4.5n}{n} = 10.5$: multiply by $n$ to get $1200 + 4.5n = 10.5n$, so $1200 = 6n$.
@answer $n = 200$ hoodies
:::

:::mistake Keeping an impossible answer
Problems in context can give a negative root, such as a speed of $-5$ km/h or a time of $-2$ h. Reject roots that make no sense in the situation, as well as extraneous roots.
:::

:::summary
- State the non-permissible values first, then multiply every term by the LCD.
- Solve the resulting linear or quadratic equation.
- Reject extraneous roots (non-permissible values) and roots that make no sense in context; "no solution" is possible.
- Work rates add: $\dfrac{1}{a} + \dfrac{1}{b} = \dfrac{1}{t}$. Travel: time $=$ distance $\div$ speed. Average cost $=$ total cost $\div$ number of items.
:::
