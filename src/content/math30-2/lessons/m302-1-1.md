A coach sorting players into lines, a grocery store grouping products into aisles, and a search engine filtering results all work with **sets**. Set theory gives you a precise language for describing groups of things and how those groups relate to each other.

## Sets and elements

:::definition Set and element
A **set** is a collection of distinct objects. Each object in a set is an **element** of the set.
- $x \in A$ means "$x$ is an element of $A$"; $x \notin A$ means "$x$ is not an element of $A$".
- $n(A)$ is the number of elements in set $A$.
:::

You can describe a set in three ways.

| Method | Example |
|---|---|
| In words | $A$ is the set of factors of 12 |
| As a list | $A = \{1, 2, 3, 4, 6, 12\}$ |
| In set-builder notation | $A = \{x \mid x \text{ is a factor of } 12,\ x \in N\}$ |

Each element is listed only once, and the order of a list does not matter: $\{3, 1, 2\}$ and $\{1, 2, 3\}$ are the same set.

:::example Listing and counting
Let $B$ be the set of prime numbers less than 20. List the elements of $B$ and find $n(B)$.
@step A prime number has exactly two factors, 1 and itself, so 1 is not prime.
@step $B = \{2, 3, 5, 7, 11, 13, 17, 19\}$
@answer $n(B) = 8$
:::

## Set-builder notation

Set-builder notation $\{x \mid \text{condition}\}$ is read "the set of all $x$ such that ...". Three number sets come up often:
- the **natural numbers** $N = \{1, 2, 3, \ldots\}$
- the **whole numbers** $W = \{0, 1, 2, 3, \ldots\}$
- the **integers** $I = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$

:::example Reading set-builder notation
List the elements of $C = \{x \mid -3 \le x < 4,\ x \in I\}$.
@step $x$ must be an integer, so negative numbers and 0 are allowed.
@step $-3 \le x$ includes $-3$, and $x < 4$ leaves out $4$.
@answer $C = \{-3, -2, -1, 0, 1, 2, 3\}$, so $n(C) = 7$.
:::

:::mistake Check the endpoints and the number set
The symbols $<$ and $>$ leave an endpoint out; $\le$ and $\ge$ include it. Also check which numbers $x$ can be: $\{x \mid 0 \le x \le 3,\ x \in N\} = \{1, 2, 3\}$, because 0 is not a natural number.
:::

## Finite, infinite and empty sets

:::definition Finite, infinite and empty sets
- A **finite set** has a countable number of elements: if you counted them, the count would end.
- An **infinite set** has an unlimited number of elements, such as $N$ or the set of even integers.
- The **empty set** has no elements. It is written $\{\ \}$ or $\varnothing$, and $n(\varnothing) = 0$.
:::

The set of people living in the world is very large, but it is finite. The set of fractions between 0 and 1 is infinite: between any two of them there is always another one.

:::example Empty or not?
Which of these sets is empty: (a) the set of even prime numbers; (b) the set of months with 32 days; (c) $\{0\}$?
@step (a) contains 2, which is even and prime, so it is not empty.
@step (c) contains one element, the number 0, so it is not empty.
@answer Only (b) is the empty set, because no month has 32 days.
:::

:::mistake The set $\{0\}$ is not empty
$\{0\}$ has one element, so $n(\{0\}) = 1$. Write the empty set as $\{\ \}$ or $\varnothing$, never as $\{0\}$ or $\{\varnothing\}$.
:::

## The universal set and subsets

:::definition Universal set, subset and disjoint sets
- The **universal set** $U$ contains all the elements being considered in a situation.
- $B$ is a **subset** of $A$, written $B \subset A$, if every element of $B$ is also an element of $A$.
- Two sets are **disjoint** if they have no elements in common.
:::

In a **Venn diagram**, the universal set is drawn as a rectangle and each set as a circle inside it. A subset is drawn inside the set that contains it.

:::example Subsets and disjoint sets
Let $U = \{1, 2, 3, \ldots, 20\}$. Let $A$ be the even numbers, $B$ the multiples of 4 and $C$ the odd numbers in $U$. How are the sets related?
@step $A = \{2, 4, 6, \ldots, 20\}$, $B = \{4, 8, 12, 16, 20\}$ and $C = \{1, 3, 5, \ldots, 19\}$.
@step Every multiple of 4 is even, so $B \subset A$. But $A$ is not a subset of $B$, because $2 \in A$ and $2 \notin B$.
@step No number is both odd and even.
@answer $B \subset A$, and $C$ is disjoint from both $A$ and $B$.
:::

:::tip Two facts about subsets
Every set is a subset of itself, and the empty set is a subset of every set.
:::

## Counting subsets

To build a subset of $\{\text{red}, \text{blue}, \text{green}\}$, decide for each element whether it is in or out. That is $2 \times 2 \times 2$ choices.

:::example All the subsets
List all the subsets of $\{\text{red}, \text{blue}, \text{green}\}$.
@step No elements: $\{\ \}$
@step One element: {red}, {blue}, {green}
@step Two elements: {red, blue}, {red, green}, {blue, green}
@step Three elements: {red, blue, green}
@answer There are 8 subsets, which is $2^3$.
:::

A set with $n$ elements has $2^n$ subsets, counting the empty set and the set itself. A set with 5 elements has $2^5 = 32$ subsets.

:::

:::summary
- A set is a collection of distinct elements; $n(A)$ counts them.
- Describe sets in words, as a list, or in set-builder notation, $\{x \mid \ldots\}$.
- $N$, $W$ and $I$ are the natural numbers, whole numbers and integers.
- The empty set $\varnothing$ has no elements; $\{0\}$ is not empty.
- $B \subset A$ when every element of $B$ is in $A$. Disjoint sets share no elements.
- A set with $n$ elements has $2^n$ subsets.
:::
