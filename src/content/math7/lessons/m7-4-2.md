At noon the temperature in Northfield is $+4^\circ\text{C}$. By evening it is $-5^\circ\text{C}$. How many degrees did it fall? Questions like this need subtraction of integers, and counters make the rules easy to see.

## Subtracting by taking away

Subtracting means taking away. Model the first integer with counters, then take away the second integer.

:::example Taking away negatives
Find $(-6) - (-2)$.
@step Show $(-6)$ with $6$ negative counters.
@step Take away $2$ negative counters.
@answer $4$ negative counters are left, so $(-6) - (-2) = -4$.
:::

:::example Taking away positives
Find $(+7) - (+3)$.
@step Show $7$ positive counters and take away $3$ of them.
@answer $(+7) - (+3) = +4$
:::

## When there are not enough counters

Sometimes you need to take away counters that are not there. Add zero pairs first. A zero pair is worth $0$, so adding it does not change the value.

:::example Taking away more than you have
Find $(+2) - (+5)$.
@step Start with $2$ positive counters. You need to take away $5$ positive counters.
@step Add $3$ zero pairs. Now there are $5$ positive and $3$ negative counters, and the value is still $+2$.
@step Take away the $5$ positive counters.
@answer $3$ negative counters are left, so $(+2) - (+5) = -3$.
:::

:::example Taking away negatives that are not there
Find $(+3) - (-2)$.
@step Start with $3$ positive counters. There are no negative counters to take away.
@step Add $2$ zero pairs, then take away the $2$ negative counters.
@answer $5$ positive counters are left, so $(+3) - (-2) = +5$.
:::

## Subtract by adding the opposite

Compare the answers from the counters with additions:
- $(+2) - (+5) = -3$ and $(+2) + (-5) = -3$
- $(+3) - (-2) = +5$ and $(+3) + (+2) = +5$

:::figure
{"type":"table","headers":["Subtraction","Answer"],"rows":[["(+3) − (+2)","+1"],["(+3) − (+1)","+2"],["(+3) − 0","+3"],["(+3) − (−1)","+4"],["(+3) − (−2)","+5"]]}
:::

The table shows a pattern: each time you subtract $1$ less, the answer goes up by $1$. Subtracting $-2$ gives the same answer as adding $+2$.

:::note Subtracting integers
To subtract an integer, **add its opposite**. Keep the first integer, change $-$ to $+$, and change the sign of the second integer. Then use the rules for adding.
:::

:::example Subtracting a positive
Find $(-9) - (+12)$.
@step Add the opposite: $(-9) - (+12) = (-9) + (-12)$.
@step Same signs: $9 + 12 = 21$, and keep the negative sign.
@answer $(-9) - (+12) = -21$
:::

:::example Subtracting a negative
Find $(-4) - (-22)$.
@step Add the opposite: $(-4) - (-22) = (-4) + (+22)$.
@step Different signs: $22 - 4 = 18$. There are more positives.
@answer $(-4) - (-22) = +18$
:::

:::mistake Two minus signs
$(+7) - (-3)$ is **not** $+4$. Subtracting $-3$ is the same as adding $+3$, so $(+7) - (-3) = +10$.
:::

:::check m7-integer-subtract 2
:::

## Several steps

When an expression has several subtractions, change each one to adding the opposite first. Then add.

:::example Three integers
Find $(-14) - (-10) - (-6)$.
@step Add the opposites: $(-14) + (+10) + (+6)$.
@step Positives: $10 + 6 = 16$. Negative: $-14$.
@step $(+16) + (-14)$: $16 - 14 = 2$, and there are more positives.
@answer $(-14) - (-10) - (-6) = +2$
:::

:::tip Subtracting on a number line
Subtracting a positive integer moves left. Subtracting a negative integer moves right, just like adding a positive.
:::

:::check m7-integer-subtract 3
:::

:::summary
- To subtract with counters, take away. If there are not enough counters, add zero pairs first.
- Subtracting an integer gives the same answer as adding its opposite: $(+3) - (-2) = (+3) + (+2) = +5$.
- After you change to adding the opposite, use the rules for adding integers.
- With several subtractions, change each one to an addition, then group the positives and the negatives.
:::
