On a January morning in a northern town, the temperature is $-8^\circ\text{C}$. By noon it rises $11$ degrees. In hockey, a player can be $+2$ in one game and $-3$ in the next. Integers help you keep track of changes like these.

## Integers and opposites

:::definition Integer
The **integers** are the whole numbers and their opposites: $\ldots, -3, -2, -1, 0, +1, +2, +3, \ldots$ Positive integers are greater than $0$. Negative integers are less than $0$. Zero is neither positive nor negative.
:::

:::definition Opposite integers
**Opposite integers** are the same distance from $0$ but on opposite sides of it, like $+3$ and $-3$.
:::

:::figure

:::

In this unit, we write each integer with its sign and put it in brackets when we add or subtract, like $(+5) + (-3)$. Then the sign of the number does not get mixed up with the operation.

## Zero pairs

You can model integers with counters. A filled counter is $+1$ and an open counter is $-1$.

:::definition Zero pair
A **zero pair** is one $+1$ counter and one $-1$ counter. Together they are worth $0$, so you can remove a zero pair without changing the value.
:::

## Adding on a number line

Start at the first integer. Adding a **positive** integer moves **right**. Adding a **negative** integer moves **left**.

:::figure
{"type":"numberLine","min":-9,"max":2,"step":1,"points":[{"value":-2,"label":"start"},{"value":-7,"label":"end"}]}
:::

:::example Two negatives
Find $(-2) + (-5)$.
@step Start at $-2$.
@step Adding $-5$ means moving $5$ steps to the left.
@answer You land on $-7$, so $(-2) + (-5) = -7$.
:::

:::figure
{"type":"numberLine","min":-5,"max":6,"step":1,"points":[{"value":4,"label":"start"},{"value":-3,"label":"end"}]}
:::

:::example Different signs
Find $(+4) + (-7)$.
@step Start at $+4$ and move $7$ steps to the left.
@step After $4$ steps you reach $0$. Then $3$ more steps take you to $-3$.
@answer $(+4) + (-7) = -3$
:::

## Adding with symbols

For bigger numbers, drawing counters takes too long. Think about the zero pairs instead.

:::note Rules for adding integers
- **Same signs:** add the sizes and keep the sign. $(-9) + (-14) = -23$
- **Different signs:** the zero pairs cancel. Subtract the sizes and use the sign of the integer with the bigger size. $(-18) + (+11) = -7$
:::

:::example Different signs
Find $(-18) + (+11)$.
@step The signs are different. $11$ zero pairs make $0$.
@step Subtract the sizes: $18 - 11 = 7$. There were more negative counters.
@answer $(-18) + (+11) = -7$
:::

:::mistake Ignoring the signs
$(-18) + (+11)$ is **not** $+29$ or $-29$. The positive and negative parts cancel each other in zero pairs, so the answer is smaller than both sizes: $-7$.
:::

:::check m7-integer-add 2
:::

## Adding several integers

You can add integers in any order. Group the positive integers, group the negative integers, then add the two results.

:::example Four integers
Find $(+12) + (-7) + (-9) + (+3)$.
@step Positive integers: $12 + 3 = 15$.
@step Negative integers: $(-7) + (-9) = -16$.
@step Combine: $(+15) + (-16)$. The signs are different: $16 - 15 = 1$, and there are more negatives.
@answer $(+12) + (-7) + (-9) + (+3) = -1$
:::

:::tip Look for opposites
Opposite integers add to $0$. In $(+6) + (-4) + (-6)$, the $(+6)$ and $(-6)$ cancel, so the sum is $-4$.
:::

:::check m7-integer-add 3
:::

:::summary
- Integers are the whole numbers and their opposites. Opposites are the same distance from $0$.
- A zero pair ($+1$ and $-1$) is worth $0$.
- On a number line, adding a positive integer moves right and adding a negative integer moves left.
- Same signs: add the sizes and keep the sign. Different signs: subtract the sizes and use the sign of the bigger size.
- To add several integers, group the positives and the negatives first.
:::
