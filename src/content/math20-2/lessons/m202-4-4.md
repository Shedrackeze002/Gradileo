A pebble dropped from a footbridge over a river valley hits the water $2.5$ s later. How high is the bridge? The fall time is modelled by $t = \sqrt{\dfrac{d}{4.9}}$, so answering the question means solving an equation with a radical in it — and checking that the answer really works.

## Undoing a root

To solve a radical equation, **isolate** the radical, then undo it: square both sides to undo a square root, or cube both sides to undo a cube root. Always **check** the answer in the original equation.

:::example A square root
Solve $\sqrt{x} + 4 = 9$.
@step Isolate the radical: $\sqrt{x} = 5$
@step Square both sides: $x = 25$
@step Check: $\sqrt{25} + 4 = 5 + 4 = 9$ ✓
@answer $x = 25$
:::

:::example A cube root
Solve $\sqrt[3]{x - 2} = -3$.
@step Cube both sides: $x - 2 = (-3)^3 = -27$
@step $x = -25$
@step Check: $\sqrt[3]{-25 - 2} = \sqrt[3]{-27} = -3$ ✓
@answer $x = -25$
:::

A cube root can be negative, because $(-3)^3 = -27$. A square root $\sqrt{\ }$ never is.

:::

## Isolate first

When the radical has a number in front or a number added to it, undo those first — in the reverse order of operations.

:::example Two steps before squaring
Solve $2\sqrt{x - 1} + 3 = 11$.
@step Subtract $3$: $2\sqrt{x - 1} = 8$
@step Divide by $2$: $\sqrt{x - 1} = 4$
@step Square: $x - 1 = 16$, so $x = 17$.
@step Check: $2\sqrt{16} + 3 = 8 + 3 = 11$ ✓
@answer $x = 17$
:::

## Extraneous roots

Squaring both sides can produce a value that does **not** satisfy the original equation.

:::definition Extraneous root
An **extraneous root** is a value found while solving that does not satisfy the original equation. It must be rejected.
:::

:::example No solution
Solve $\sqrt{x + 5} + 6 = 2$.
@step Isolate the radical: $\sqrt{x + 5} = -4$
@step A square root is never negative, so this cannot be true.
@step If you square anyway: $x + 5 = 16$, so $x = 11$. Check: $\sqrt{16} + 6 = 10$, not $2$. ✗
@answer $x = 11$ is extraneous, so there is **no solution**.
:::

:::mistake Skipping the check
Squaring turns $\sqrt{x + 5} = -4$ into $x + 5 = 16$, which **does** have a solution. The only way to catch the extraneous root is to substitute it back into the original equation. Make the check a habit for every square-root equation.
:::

:::check m202-radical-equation 2
:::

## Reasoning with a graph

Sometimes the $x^2$ terms cancel after squaring. Compare these two equations.

:::example Same steps, different outcomes
Solve (a) $\sqrt{x^2 + 9} = x + 1$ (b) $\sqrt{x^2 + 9} = x - 1$.
@step (a) Square: $x^2 + 9 = x^2 + 2x + 1$, so $8 = 2x$ and $x = 4$. Check: $\sqrt{25} = 5$ and $4 + 1 = 5$ ✓
@step (b) Square: $x^2 + 9 = x^2 - 2x + 1$, so $8 = -2x$ and $x = -4$. Check: $\sqrt{25} = 5$ but $-4 - 1 = -5$ ✗
@answer (a) $x = 4$ (b) no solution
:::

The graph explains it: the curve $y = \sqrt{x^2 + 9}$ meets the line $y = x + 1$ at $(4, 5)$, but it never meets the line $y = x - 1$.

## Radical equations in context

:::example How high is the bridge?
The fall time of an object is modelled by $t = \sqrt{\dfrac{d}{4.9}}$, where $t$ is in seconds and $d$ is the distance fallen in metres. A pebble takes $2.5$ s to reach the water. How high is the bridge, to the nearest tenth of a metre?
@step $2.5 = \sqrt{\dfrac{d}{4.9}}$
@step Square both sides: $6.25 = \dfrac{d}{4.9}$
@step $d = 4.9 \times 6.25 = 30.625$
@answer The bridge is about $30.6$ m above the water.
:::

:::example The volume of an exercise ball
The radius of a sphere is $r = \sqrt[3]{\dfrac{3V}{4\pi}}$. An exercise ball has a radius of $30$ cm. Find its volume.
@step Cube both sides: $27\,000 = \dfrac{3V}{4\pi}$
@step $V = \dfrac{4\pi(27\,000)}{3} = 36\,000\pi \approx 113\,097$
@answer The ball holds about $113\,097$ cm³ of air (about $113$ L).
:::

:::tip Is the answer reasonable?
A $30.6$ m bridge is about as tall as a ten-storey building, and a fall of $2.5$ s feels about right for that height. A quick reasonableness check catches slips such as forgetting to square.
:::

:::summary
- Isolate the radical, then square (for $\sqrt{\ }$) or cube (for $\sqrt[3]{\ }$) both sides.
- A square root is never negative; a cube root can be.
- Squaring can create **extraneous roots** — check every answer in the original equation.
- If no candidate checks, the equation has **no solution**.
- In context, solve for the unknown, round only at the end, and ask whether the answer is reasonable.
:::
