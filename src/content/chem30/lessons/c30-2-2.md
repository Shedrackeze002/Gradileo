When zinc reacts with copper(II) ions, the charges show at once which substance lost electrons. But when natural gas burns, $\ce{CH4 + 2O2 -> CO2 + 2H2O}$, every substance is a molecule with no charge at all, and yet carbon has clearly been oxidised: it has combined with oxygen. To follow electrons through molecules and polyatomic ions, chemists use a kind of electron bookkeeping called oxidation numbers.

In this lesson you will assign oxidation numbers to the atoms in elements, compounds and ions, and use changes in oxidation numbers to decide whether a reaction is a redox reaction, what is oxidised and reduced, and which reactants are the oxidising and reducing agents.

## What an oxidation number is

In a covalent bond the electrons are shared, but not always equally: the more electronegative atom pulls them closer. An oxidation number pretends that the more electronegative atom takes the shared electrons completely.

:::definition Oxidation number
The **oxidation number** (or **oxidation state**) of an atom is the charge it would have if every bond in the substance were ionic, with the shared electrons given to the more electronegative atom.
:::

In water, oxygen is more electronegative than hydrogen, so it is counted as taking both bonding pairs: oxygen is $-2$ and each hydrogen is $+1$. These are not real charges; they are a way of keeping count. Oxidation numbers are written with the sign first, $+2$, while ion charges are written with the sign last, $2+$.

## The rules

Apply the rules in this order. The first rule that fits an atom decides its oxidation number, and the last rule finds the one atom left.

| Rule | Examples |
|---|---|
| 1. An atom in an element is 0. | $\ce{Na}$, $\ce{O2}$, $\ce{Cl2}$, $\ce{P4}$, $\ce{S8}$: all 0 |
| 2. A monatomic ion has the oxidation number of its charge. | $\ce{Na+}$ is $+1$, $\ce{Fe^3+}$ is $+3$, $\ce{S^2-}$ is $-2$ |
| 3. In compounds, group 1 metals are $+1$, group 2 metals $+2$ and aluminium $+3$. | $\ce{K}$ in $\ce{KMnO4}$ is $+1$ |
| 4. Fluorine in a compound is $-1$. | $\ce{F}$ in $\ce{OF2}$ is $-1$ |
| 5. Hydrogen is $+1$, except in metal hydrides, where it is $-1$. | $\ce{H}$ in $\ce{H2O}$ is $+1$; in $\ce{NaH}$ it is $-1$ |
| 6. Oxygen is $-2$, except in peroxides, where it is $-1$, and with fluorine. | $\ce{O}$ in $\ce{CO2}$ is $-2$; in $\ce{H2O2}$ it is $-1$ |
| 7. The oxidation numbers add up to 0 in a compound, and to the charge in a polyatomic ion. | $\ce{SO4^2-}$: they add up to $-2$ |

:::example A compound
What is the oxidation number of sulfur in sulfuric acid, $\ce{H2SO4}$?
@step Hydrogen is $+1$ and oxygen is $-2$. Let $x$ be the oxidation number of sulfur.
@step The oxidation numbers add up to 0: $2(+1) + x + 4(-2) = 0$, so $x - 6 = 0$.
@answer $x = +6$
:::

When two elements are left without a rule, as in $\ce{FeCl3}$ or $\ce{PCl5}$, the more electronegative one takes the value it has as a simple ion: chlorine is $-1$, as in a chloride ion. Then iron is $+3$ and phosphorus is $+5$.

:::example A polyatomic ion
What is the oxidation number of chromium in the dichromate ion, $\ce{Cr2O7^2-}$?
@step Oxygen is $-2$. Let $x$ be the oxidation number of chromium; there are two chromium atoms.
@step The oxidation numbers add up to the charge of the ion: $2x + 7(-2) = -2$, so $2x = 12$.
@answer $x = +6$
:::

:::mistake Adding up to zero in an ion
For the permanganate ion, $\ce{MnO4^-}$, writing $x + 4(-2) = 0$ gives $+8$, which is wrong. The oxidation numbers of an ion add up to its charge: $x + 4(-2) = -1$, so manganese is $+7$.
:::

:::check c30-oxidation-number 2
:::

The exceptions matter. In a **peroxide** two oxygen atoms are bonded to each other, so neither can take the electrons of that bond, and each is $-1$. In a **metal hydride**, hydrogen is bonded to a metal less electronegative than itself, so it takes the electrons and is $-1$.

:::example A peroxide
What is the oxidation number of oxygen in hydrogen peroxide, $\ce{H2O2}$?
@step Hydrogen is $+1$. If oxygen were $-2$, the total would be $2(+1) + 2(-2) = -2$, not 0, so this must be a peroxide.
@step $2(+1) + 2x = 0$, so $2x = -2$.
@answer Oxygen is $-1$.
:::

:::note Averages
Some formulas give an oxidation number that is not a whole number: iron in $\ce{Fe3O4}$ works out to $+\frac{8}{3}$. The compound contains both $\ce{Fe^2+}$ and $\ce{Fe^3+}$ ions, and $+\frac{8}{3}$ is their average. The carbon atoms of ethanol, $\ce{C2H5OH}$, are not alike either, and the rules give their average, $-2$.
:::

## Oxidation numbers and redox

Losing electrons makes an atom's oxidation number go up; gaining electrons makes it go down. That gives a test for redox that works for molecules too.

:::definition Oxidation and reduction by oxidation numbers
**Oxidation** is an increase in oxidation number, and **reduction** is a decrease. A reaction is a redox reaction when the oxidation numbers of some elements change.
:::

In the burning of methane, carbon goes from $-4$ in $\ce{CH4}$ to $+4$ in $\ce{CO2}$: it is oxidised. Oxygen goes from 0 in $\ce{O2}$ to $-2$ in both products: it is reduced. Hydrogen stays $+1$.

| | $\ce{CH4}$ | $\ce{O2}$ | $\ce{CO2}$ | $\ce{H2O}$ |
|---|---|---|---|---|
| C | $-4$ | | $+4$ | |
| H | $+1$ | | | $+1$ |
| O | | 0 | $-2$ | $-2$ |

:::example Is it redox?
Is $\ce{AgNO3 + NaCl -> AgCl + NaNO3}$ a redox reaction?
@step Reactants: Ag $+1$, N $+5$, O $-2$ in $\ce{AgNO3}$; Na $+1$, Cl $-1$ in $\ce{NaCl}$.
@step Products: Ag $+1$, Cl $-1$ in $\ce{AgCl}$; Na $+1$, N $+5$, O $-2$ in $\ce{NaNO3}$.
@answer No oxidation number changes, so it is not a redox reaction. It is a double replacement: the ions swap partners.
:::

To find the oxidising and reducing agents, look for the element whose oxidation number falls and the one whose oxidation number rises. The agents are the **reactants** that contain them.

:::example Copper in nitric acid
Copper dissolves in dilute nitric acid: $\ce{3Cu + 8HNO3 -> 3Cu(NO3)2 + 2NO + 4H2O}$. What is oxidised and what is reduced, and what are the oxidising and reducing agents?
@step Copper goes from 0 to $+2$: it is oxidised.
@step Nitrogen is $+5$ in $\ce{HNO3}$ and $+2$ in $\ce{NO}$: it is reduced. The nitrogen in the nitrate ions of $\ce{Cu(NO3)2}$ stays $+5$.
@step Hydrogen ($+1$) and oxygen ($-2$) do not change.
@answer Copper is oxidised and nitrogen is reduced. The oxidising agent is $\ce{HNO3}$, the reactant that contains the nitrogen reduced; the reducing agent is $\ce{Cu}$.
:::

:::mistake Naming an element as the agent
In the last example, "nitrogen" is the element reduced, but the oxidising agent is the whole reactant, $\ce{HNO3}$. An agent is a substance you could put in a bottle: give its formula, not one of its elements.
:::

:::summary
- An **oxidation number** is the charge an atom would have if all its bonds were ionic. It is written with the sign first: $+2$, $-1$.
- Rules: elements 0; monatomic ions their charge; group 1 $+1$, group 2 $+2$, aluminium $+3$; F $-1$; H $+1$ (but $-1$ in metal hydrides); O $-2$ (but $-1$ in peroxides); the total is 0 for a compound and the charge for an ion.
- **Oxidation** is an increase in oxidation number; **reduction** is a decrease. If no oxidation number changes, the reaction is not redox.
- The oxidising agent is the reactant containing the element reduced; the reducing agent is the reactant containing the element oxidised.
:::
