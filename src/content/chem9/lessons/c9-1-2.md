Every carbon atom has 6 protons, but not every carbon atom has the same mass. Two numbers tell you exactly what is inside an atom, and they explain why some atoms of the same element are heavier than others.

## Atomic number and mass number

:::definition Atomic number and mass number
The **atomic number** is the number of **protons** in an atom. It decides which element the atom is: every atom with 6 protons is carbon.

The **mass number** is the number of **protons plus neutrons**.

In an atom, the number of electrons equals the number of protons.
:::

The two numbers are often written beside the symbol, with the mass number on top:

$$^{23}_{11}\text{Na}$$

This sodium atom has 11 protons, 11 electrons, and $23 - 11 = 12$ neutrons.

| To find | Use |
|---|---|
| protons | atomic number |
| electrons (in an atom) | atomic number |
| neutrons | mass number − atomic number |

:::example Inside an atom of chlorine
Chlorine has atomic number 17 and mass number 35. How many protons, neutrons and electrons are in the atom?
@step Protons = atomic number = 17.
@step Electrons = protons = 17.
@step Neutrons = 35 − 17 = 18.
@answer 17 protons, 18 neutrons and 17 electrons.
:::

:::mistake Electrons do not count towards the mass number
Electrons are so light that they are left out. The mass number counts only protons and neutrons.
:::

## Isotopes

:::definition Isotopes
**Isotopes** are atoms of the same element with **the same number of protons** but **different numbers of neutrons**, so they have different mass numbers.
:::

An isotope is often named with its mass number: carbon-12 and carbon-14.

| Isotope | Protons | Neutrons | Mass number |
|---|---|---|---|
| carbon-12 | 6 | 6 | 12 |
| carbon-14 | 6 | 8 | 14 |
| chlorine-35 | 17 | 18 | 35 |
| chlorine-37 | 17 | 20 | 37 |

Isotopes of an element have the same number of electrons, and chemical reactions involve electrons, so isotopes react in exactly the same way. Only their masses differ. Carbon-14 is slightly radioactive, which lets scientists find the age of ancient wood and bone.

:::example Counting neutrons in an isotope
How many neutrons are in an atom of hydrogen-2? (Hydrogen has atomic number 1.)
@step The mass number is 2.
@answer Neutrons = 2 − 1 = 1.
:::

:::summary
- **Atomic number** = protons. In an atom, electrons = protons.
- **Mass number** = protons + neutrons, so neutrons = mass number − atomic number.
- **Isotopes** have the same number of protons but different numbers of neutrons; they react in the same way.
:::
