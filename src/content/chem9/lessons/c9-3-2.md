A word equation names the substances in a reaction. A symbol equation goes further: it shows the formulas, and how many of each particle react. Because atoms are never created or destroyed, a symbol equation must be balanced.

## Reading a symbol equation

:::definition Symbol equation
A **symbol equation** uses formulas instead of names. A big number in front of a formula, a **coefficient**, counts whole molecules or units. A symbol equation is **balanced** when each kind of atom appears the same number of times on both sides.

$$\ce{2H2 + O2 -> 2H2O}$$
:::

To count the atoms of an element in a formula with a coefficient, multiply the coefficient by the small number after the symbol.

:::example Counting atoms
Is $\ce{2H2 + O2 -> 2H2O}$ balanced?
@step Hydrogen: left $2 \times 2 = 4$; right $2 \times 2 = 4$.
@step Oxygen: left 2; right $2 \times 1 = 2$.
@answer Yes: each kind of atom has the same count on both sides.
:::

## Balancing equations

:::definition How to balance
1. Write the correct formulas. **Never change them.**
2. Count each kind of atom on both sides.
3. Add **coefficients** in front of formulas until every count matches.
4. Check every element again at the end.
:::

:::example Magnesium burning
Balance $\ce{Mg + O2 -> MgO}$.
@step Oxygen: 2 on the left, 1 on the right, so put 2 in front of MgO: $\ce{Mg + O2 -> 2MgO}$.
@step Now magnesium: 1 on the left, 2 on the right, so put 2 in front of Mg.
@answer $\ce{2Mg + O2 -> 2MgO}$
:::

:::example Methane burning
Balance $\ce{CH4 + O2 -> CO2 + H2O}$.
@step Carbon: 1 and 1. Balanced.
@step Hydrogen: 4 on the left, so put 2 in front of $\ce{H2O}$.
@step Oxygen: right side now has $2 + 2 = 4$, so put 2 in front of $\ce{O2}$.
@answer $\ce{CH4 + 2O2 -> CO2 + 2H2O}$
:::

:::mistake Do not change the small numbers
Changing $\ce{H2O}$ to $\ce{H2O2}$ "balances" the oxygen, but $\ce{H2O2}$ is hydrogen peroxide, a different substance. Only change the coefficients.
:::

:::summary
- A symbol equation uses formulas; coefficients count whole molecules.
- Balanced means the same number of each kind of atom on both sides, showing conservation of mass.
- Balance by changing coefficients only, never the formulas.
:::
