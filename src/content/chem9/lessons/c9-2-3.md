Every compound has a name that tells a chemist what is in it. Ionic and covalent compounds are named in slightly different ways, and a few simple rules let you name thousands of substances.

## Naming ionic compounds

:::definition Naming an ionic compound
1. Name the **positive ion** (usually the metal) first, unchanged.
2. Name the **negative ion** second:
   - a single non-metal ion ends in **-ide**: chloride, oxide, sulfide, nitride;
   - a polyatomic ion keeps its own name: hydroxide, nitrate, sulfate, carbonate.
:::

| Formula | Name |
|---|---|
| $\ce{NaCl}$ | sodium chloride |
| $\ce{MgO}$ | magnesium oxide |
| $\ce{K2S}$ | potassium sulfide |
| $\ce{CaCO3}$ | calcium carbonate |
| $\ce{NaNO3}$ | sodium nitrate |
| $\ce{(NH4)2SO4}$ | ammonium sulfate |

The numbers in an ionic formula are **not** spoken in the name: $\ce{CaCl2}$ is calcium chloride, not calcium dichloride.

:::example Naming a compound
Name $\ce{Al2(SO4)3}$.
@step The positive ion is aluminium.
@step $\ce{SO4}$ is the sulfate ion.
@answer Aluminium sulfate.
:::

:::mistake -ide or -ate?
**-ide** means just the element: sulfide is $\text{S}^{2-}$. **-ate** means the element with oxygen: sulfate is $\ce{SO4^2-}$.
:::

## Naming covalent compounds

Two non-metals can join in several ratios (CO and CO₂), so covalent names use **prefixes** to give the number of each atom.

:::definition Prefixes
| Number | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| Prefix | mono | di | tri | tetra | penta | hexa |

The first element takes a prefix only if there is more than one atom of it. The second element always takes a prefix and ends in **-ide**.
:::

| Formula | Name |
|---|---|
| $\ce{CO}$ | carbon monoxide |
| $\ce{CO2}$ | carbon dioxide |
| $\ce{SO3}$ | sulfur trioxide |
| $\ce{N2O4}$ | dinitrogen tetraoxide |
| $\ce{PCl5}$ | phosphorus pentachloride |

:::example From name to formula
Write the formula of dinitrogen monoxide.
@step "Di" means 2 nitrogen atoms; "mono" means 1 oxygen atom.
@answer $\ce{N2O}$
:::

:::tip Monoxide
"Mono" + "oxide" is shortened to **monoxide**.

:::summary
- Ionic: positive ion first, then the negative ion (-ide, or the polyatomic ion's name); no number prefixes.
- Covalent: prefixes give the number of atoms (mono, di, tri, tetra, penta); the second element ends in -ide.
- The first element in a covalent name never takes "mono".
:::
