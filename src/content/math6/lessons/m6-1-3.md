The temperature in a mountain town is $-6^\circ\text{C}$ and then rises $9$ degrees. Kai owes \$12 and then earns \$8. To find out what happens, we add positive and negative numbers. Zero is the key.

## A number plus its opposite

We can model integers with counters. A filled counter (+) stands for $1$. An open counter ($-$) stands for $-1$.

:::definition Zero pair
A **zero pair** is one $+1$ counter and one $-1$ counter. Together they are worth $0$.
:::

:::

These counters show $4 + (-4)$. There are $4$ zero pairs and nothing is left over. So $4 + (-4) = 0$.

The sum of any number and its opposite (its additive inverse) is $0$.

:::example Zero in many ways
Write three different sums that equal $0$.
@step Pick any number and add its opposite: $9 + (-9) = 0$ and $-15 + 15 = 0$.
@step You can use more than two numbers too: $2 + 5 + (-7) = 0$, because $2 + 5 = 7$ and $7 + (-7) = 0$.
@answer $9 + (-9)$, $-15 + 15$ and $2 + 5 + (-7)$ all equal $0$. There are many more!
:::

:::

## Two positives or two negatives

Two positive numbers add to a positive number: $3 + 4 = 7$.

Two negative numbers add to a negative number. There are no zero pairs, so just count the negative counters.

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":8,"yMin":0,"yMax":3,"step":9},"points":[{"x":1,"y":1,"color":"accent","open":true,"label":"−"},{"x":2,"y":1,"color":"accent","open":true,"label":"−"},{"x":3,"y":1,"color":"accent","open":true,"label":"−"},{"x":4,"y":1,"color":"accent","open":true,"label":"−"},{"x":5,"y":1,"color":"accent","open":true,"label":"−"},{"x":6,"y":1,"color":"accent","open":true,"label":"−"},{"x":7,"y":1,"color":"accent","open":true,"label":"−"}],"hideTickLabels":true,"caption":"3 + 4 negative counters"}
:::

:::example Two negative numbers
Find $-3 + (-4)$.
@step $-3$ is $3$ negative counters and $-4$ is $4$ more negative counters.
@step There are no zero pairs. Count them: $7$ negative counters.
@answer $-3 + (-4) = -7$
:::

:::mistake The sum of two negatives is not positive
$-3 + (-4)$ is not $7$. If you owe \$3 and then owe \$4 more, you owe \$7. That is $-7$.
:::

## A positive plus a negative

When one number is positive and the other is negative, look for zero pairs. Split one number so that part of it is the opposite of the other number.

:::figure
{"type":"plane","grid":{"xMin":0,"xMax":8,"yMin":0,"yMax":3,"step":9},"points":[{"x":1,"y":2,"color":"brand","label":"+"},{"x":2,"y":2,"color":"brand","label":"+"},{"x":3,"y":2,"color":"brand","label":"+"},{"x":4,"y":2,"color":"brand","label":"+"},{"x":5,"y":2,"color":"brand","label":"+"},{"x":6,"y":2,"color":"brand","label":"+"},{"x":7,"y":2,"color":"brand","label":"+"},{"x":1,"y":1,"color":"accent","open":true,"label":"−"},{"x":2,"y":1,"color":"accent","open":true,"label":"−"},{"x":3,"y":1,"color":"accent","open":true,"label":"−"},{"x":4,"y":1,"color":"accent","open":true,"label":"−"},{"x":5,"y":1,"color":"accent","open":true,"label":"−"}],"hideTickLabels":true,"caption":"7 positive and 5 negative counters"}
:::

:::example Zero plus another number
Find $7 + (-5)$.
@step Split $7$ into $2 + 5$: $\quad 7 + (-5) = 2 + 5 + (-5)$
@step $5$ and $-5$ make $0$ (five zero pairs): $\quad 2 + 0$
@answer $7 + (-5) = 2$
:::

:::example When the negative number is bigger
Find $4 + (-11)$.
@step $-11$ has the greater magnitude. Split it: $-11 = (-4) + (-7)$.
@step $4 + (-11) = 4 + (-4) + (-7)$
@step $4$ and $-4$ make $0$: $\quad 0 + (-7)$
@answer $4 + (-11) = -7$
:::

:::example The temperature rises
In a mountain town it is $-6^\circ\text{C}$. The temperature rises $9$ degrees. What is the new temperature?
@step New temperature $= -6 + 9$. Split $9$ into $6 + 3$.
@step $-6 + 6 + 3 = 0 + 3 = 3$
@answer The new temperature is $3^\circ\text{C}$.
:::

:::

## Writing a difference as a sum

Subtracting a number is the same as adding its opposite.

$$5 - 8 = 5 + (-8)$$

:::example Write the difference as a sum
Write $5 - 8$ as a sum. Then find its value.
@step The opposite of $8$ is $-8$, so $5 - 8 = 5 + (-8)$.
@step Split $-8$ into $(-5) + (-3)$: $\quad 5 + (-5) + (-3) = 0 + (-3)$
@answer $5 - 8 = 5 + (-8) = -3$
:::

:::mistake Changing the wrong number
In $5 - 8$, keep the first number the same. Only the number being subtracted changes to its opposite: $5 + (-8)$, not $-5 + 8$.
:::

:::check m6-integer-sums 3
:::

:::summary
- A zero pair ($+1$ and $-1$) is worth $0$. A number plus its opposite is $0$, and $0$ can be written as a sum in many ways.
- Two positives add to a positive. Two negatives add to a negative: $-3 + (-4) = -7$.
- For a positive plus a negative, split one number to make a zero pair: $7 + (-5) = 2 + 5 + (-5) = 2 + 0 = 2$.
- Subtracting a number is the same as adding its opposite: $5 - 8 = 5 + (-8)$.
:::
