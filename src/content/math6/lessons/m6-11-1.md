A bean plant grows taller every week. The longer you wait, the taller it gets. Two quantities change together here, and one of them depends on the other. Mathematicians call this kind of relationship a **function**.

## Two quantities that change together

:::definition Variable
A **variable** is a quantity that can change, such as time, height or cost. We often use a letter for it.
:::

:::definition Function
A **function** connects two changing quantities so that each value of the first quantity gives **exactly one** value of the second.
:::

:::definition Independent and dependent variables
The **independent variable** is the quantity you choose or that changes on its own (often time). The **dependent variable** changes because of it. Its value **depends on** the independent variable.
:::

:::example Which variable is which?
A bean plant is $4$ cm tall. It grows $3$ cm each week. Which is the independent variable and which is the dependent variable?
@step The height of the plant changes because weeks go by.
@step So the height depends on the number of weeks.
@answer The number of weeks is the independent variable. The height of the plant is the dependent variable.
:::

The $3$ cm per week is not a variable. It stays the same the whole time.

## Change over time

Many functions show how something changes over time: the height of a person or a plant, the temperature during a day, or the distance travelled on a trip. In these situations, **time is the independent variable**. Time keeps going no matter what, and the other quantity changes as time passes.

:::example Temperature during the day
A weather station in a city records the temperature every hour. Which statement is true?
@step The temperature changes as the hours pass. The hours do not change because of the temperature.
@answer The time is the independent variable, and the temperature is the dependent variable.
:::

:::mistake Getting it backwards
Ask: "Which one changes **because of** the other?" The one that changes because of the other is the dependent variable. The time does not depend on the temperature.
:::

:::check m6-function-variables 2
:::

## The rule

A function has a **rule** that turns each value of the independent variable into the value of the dependent variable. For the bean plant, the rule is: **multiply the number of weeks by $3$, then add $4$**.

:::example Using the rule
How tall is the bean plant after $2$ weeks?
@step Multiply the weeks by $3$: $2 \times 3 = 6$
@step Add the starting height: $6 + 4 = 10$
@answer After $2$ weeks, the plant is $10$ cm tall.
:::

:::tip Test a rule on every row
A rule must work for every value, not just one. Test it on two or three values before you trust it.
:::

:::check m6-function-variables 3
:::

## Tables of values

:::definition Table of values
A **table of values** lists values of the independent variable in the first column and the matching values of the dependent variable in the second column.
:::

:::figure
{"type":"table","headers":["Weeks, $w$","Height, $h$ (cm)"],"rows":[["0","4"],["1","7"],["2","10"],["3","13"],["4","16"]]}
:::

:::example Filling in a table
Use the rule to check the row for $w = 4$.
@step Multiply by $3$: $4 \times 3 = 12$
@step Add $4$: $12 + 4 = 16$ ✓
@answer When $w = 4$, $h = 16$. Each row goes up by $3$ cm, because the plant grows $3$ cm each week.
:::

## Points in the Cartesian plane

Each row of a table is an ordered pair. The independent variable gives the $x$-coordinate and the dependent variable gives the $y$-coordinate. Plot the pairs as points in the Cartesian plane.

:::figure

:::

The points are $(0, 4)$, $(1, 7)$, $(2, 10)$, $(3, 13)$ and $(4, 16)$. The table and the graph show the **same function** in two ways.

:::mistake Swapping the coordinates
The independent variable always goes first. The point for week $2$ is $(2, 10)$, not $(10, 2)$.
:::

:::summary
- A function connects two changing quantities. Each value of the independent variable gives exactly one value of the dependent variable.
- The dependent variable depends on the independent variable. In change over time, time is the independent variable.
- The rule tells how to get the dependent value from the independent value.
- A table of values lists the independent variable first and the dependent variable second.
- Each row is a point $(x, y)$ in the Cartesian plane: independent variable across, dependent variable up.
:::
